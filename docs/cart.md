## 2. 프롬프트 (cam0005, 원본 120번; `cart/seed_cart.py build`, 명세 `Data/Cart/review/f120/spec_f120.json`)

SAM 3 이미지 모델(동결)의 문장 프롬프트 인스턴스를 위치로 고르거나 박스·점 프롬프트로 만들고, 겹치는 곳은 명세 순서(뒤가 이김)로 칠함.

| id | 객체 | 만든 방법 |
|---|---|---|
| 1–5 | 사람: 카트 끄는 사람, 노트북 학생, 체크무늬 셔츠, 흰 셔츠, 곱슬머리 | 문장 "person" 인스턴스 (SCSegGaussians 번호와 같은 순서) |
| 6 | 북카트 + 안의 책 | "cart" + 책 줄 박스, 구멍 채움 |
| 7 | 테이블 + 위 물건 | "table" + "lamp" 전부 + 테이블에 닿는 "book" + 꽃병·작은 화분 + 인형 박스, 구멍 채움 |
| 8–10 | 3·4·5번이 읽는 책 | 박스(+점) |
| 11–12 | 노트북 (학생 것, 테이블 가운데 것) | 박스 |
| 13 | 카트 위 추천도서 안내판 | 박스 |
| 14–17 | 2·3·4·5번이 앉은 의자 (4번 의자는 걸친 재킷 포함) | "chair" 인스턴스 |
