# CROOM 링 정답 주석 지침 (초안, 2026-10-23)

> 계획 [iccv2027-plan.md](iccv2027-plan.md) WP3 "필수 추가: CROOM 링 새 정답", 사용자 결정 D4. 이 문서의 규칙(대상·순간 선택·주석 방식·품질 검사)은 **주석 시작 전에 커밋**하고, 완성된 정답의 sha256 목록은 **어떤 방법의 디코딩보다 먼저** 커밋합니다. 그 뒤 규칙은 바꾸지 않습니다. 도구 `stage1/annot/`(서버 `server.py`, 준비 `prep_croom.py`, 검사 `check.py`), 실행 `stage1/annot/run_server.sh`.

## 1. 대상

- 촬영: `PlenopticServer1/CROOM/JPG/` 의 T03_walking_rsp_out, T04_sidestep_out, T05_walk_out, T07_walkthrough_out(32대, 3840×2160). **T06은 쓰지 않습니다**(900번이 개발에 쓰여 오염).
- 순간: 촬영당 2개(G3 실패 경로: 1개). 선택 규칙(예측을 보지 않고, 입력만으로): 촬영 길이의 **1/3 지점과 2/3 지점 프레임**(프레임 수 N → round(N/3), round(2N/3)). 사람이 서로 겹쳐 대부분 카메라에서 분리가 불가능하면 ±30프레임 안에서 가장 가까운 분리 가능한 프레임으로 옮기고 그 사유를 `index.json`에 적습니다.
  - 예외(기록): T04의 첫 순간은 도구 시험용으로 규칙 확정 전에 임의로 고른 **1000번**(0.37 지점)이며, 사용자가 10-23에 32대 전부를 주석했으므로 910번 대신 그대로 씁니다(예측을 본 적 없음; 로그 `annot/log.jsonl` 237건, 36분).
  - 준비된 순간: T03 4181·8363, T04 1000·1819, T05 568·1136, T07 2023·4045(`stage1/annot/prep_croom.py`, 원본 sha256은 각 `index.json`).
- 객체: 그 순간 장면에 있는 **사람 전원**과 **큰 소품**(의자·카트·테이블처럼 여러 카메라에서 보이는 것). 작은 물체(한 변이 긴 쪽 기준 이미지의 2 % 미만)와 배경 구조물은 뺍니다. 뺀 것은 `objects.json`에 적지 않고, 지침의 이 규칙만 인용합니다.
- 카메라: 32대 전부. 객체가 안 보이는 카메라는 "이 카메라에 없음"으로 표시합니다(빈 마스크).

## 2. 주석 방식 (MUVOD §III-C의 1단계를 모든 카메라에 적용; 뷰 간 전파 없음)

1. 카메라마다 독립적으로: 객체를 고르고 **점(+/−) 또는 박스**로 SAM 3 단일 이미지 마스크를 받습니다.
2. **붓으로 수정**(원본 해상도): 빠진 부분 더하고 새어 나간 부분 지움. 경계는 보이는 그대로(모달). 다른 객체·사람에 가린 부분은 넣지 않습니다. 유리·망 뒤로 보이는 부분은 넣습니다.
3. 저장. 같은 사람이 여러 카메라에서 **같은 ID**가 되도록 이름(옷 색·위치)으로 구분합니다. 뷰 간 정체성은 주석자의 판단이며 어떤 자동 전파도 쓰지 않습니다.
4. 겹침: 한 화소는 한 객체. 앞 객체가 뒤 객체를 가리면 앞 객체가 가집니다(기본값: 먼저 저장된 화소 유지, 필요하면 "덮어쓰기" 체크).
5. 절단: 이미지 경계에서 잘린 객체는 보이는 부분만.

금지: 우리 방법·기준선의 예측을 보는 것, SAM 2/SAM 3 영상 전파·XMem 등으로 다른 카메라의 초안을 만드는 것, 3D 투영으로 프롬프트를 만드는 것. (이유: 시험 대상이 뷰 간 대응·전파이므로 정답이 그 도구를 닮으면 안 됨. [stage1-E15.md](stage1-E15.md) §5의 "경우 Z" 참고.)

## 3. 품질 검사

- `check.py`: 순간마다 카메라별 객체 집합·면적, 빈 마스크, 저장되지 않은 카메라, 겹침 0 확인, 객체별로 보이는 카메라 수(사람은 보통 20대 이상이어야 함; 적으면 ID 혼동 의심).
- **이중 주석 10 %**: 순간마다 카메라 3대를 미리 정한 규칙(번호 0·11·22)으로 두 번째 주석자가 독립적으로 그리고, 객체별 IoU와 ID 일치를 보고합니다. 두 번째 주석자의 결과는 정답에 섞지 않습니다(보고만).
- 완료 뒤: `labels/*.png`·`objects.json`·`index.json`의 sha256 목록을 `stage1/annot/croom_sha256.json`에 적어 커밋. 이후 수정은 새 커밋에 사유와 함께.
