## 3. 읽기 (주장 C2와 TEST에의 함의)

1. 계획 §G5의 CROOM 기준 "G0 대비 비열등(ΔJ CI 하한 > −0.01)"은 T04 같은 순간에서는 **AB가 G0에 못 미칠 가능성**이 큽니다(AB_t06 평균 0.93 vs G0 0.98). C2(링 안전)는 "C0의 먼 뷰 붕괴를 고친다"는 뜻으로는 성립하지만, "링에서 전파 기준선보다 낫다"는 뜻으로는 T04에서 성립하지 않습니다. TEST(여섯 명이 겹치는 T03, 걷는 T05, 통과 T07)에서 전파가 어디서 깨지는지가 관건이며, 결과가 어떻든 그대로 보고합니다.
2. T06(E15)에서 G0가 어땠는지는 E15에 기록이 없습니다(E15는 AB·C0·B-rep 등만). TEST 전에 T06에도 링 순서 G0를 한 번 재어 두는 것이 비교의 기준이 됩니다(T06은 개발 장면이므로 허용).
3. **등록 사항(TEST 디코딩 전 고정, 사용자 결정)**: ① 링 순서(§1; 입력 사실이므로 등록 필수), ② 등록(π³) 방식 — 단일 순간 32장(현 규약; 리그 검사 불합격이면 AB = C0) 또는 **보정 순간 동시 등록**(T06 #900 입력 이미지 32장을 함께; T04에서 네 기준 합격), ③ G0·번호순 기준선(SAM 2.1·Cutie의 index 순, NG-idx)의 순서 = 링 순서. ②의 보정 순간은 정답·예측과 무관한 입력 이미지만 쓰지만 "순간 하나의 이미지만 쓴다"는 규약을 바꾸므로 TEST 전에 정해야 합니다(T06 #900 대신 T06의 다른 프레임을 써도 됨).
4. T03 #4181(TEST)의 입력만 쓴 진단(§4): 단일 π³로도 네 기준 리그 검사 합격(φ 0.07·0.035·0.000·0.033)이지만 링 순서상 카메라 22→23 사이에 중앙값 4.9배의 간격(방위각 −36°)이 하나 있습니다. 보정 동시 등록에서는 간격이 없습니다. **T03 기준 0·16에는 보이는 객체가 없고 기준 8에는 p1뿐**이라(§5 기준 규칙은 기준에 없는 객체를 평가하지 않음) 0·8·16·24 규칙으로는 T03이 사실상 기준 24(6명)·8(1명)만 남습니다. 규칙을 바꾸려면 디코딩 전에 바꿔야 합니다(예: 객체가 보이는 카메라 중 사분점에 가장 가까운 것).
