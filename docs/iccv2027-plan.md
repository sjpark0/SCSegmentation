## 1. 논문의 목표와 주장

**문제.** 카메라 리그가 동기화돼 있고, 한 순간만 봅니다.
- 한 카메라(c_ini)에 여러 객체의 마스크가 주어집니다. 사람, 소품, 벽 같은 환경 객체가 모두 들어갑니다.
- 나머지 모든 카메라에서 같은 객체를 분리합니다.
- 카메라 보정은 쓰지 않습니다.

**방법.** 현재 `geoset_rep_xs`에 링 수정을 더합니다.
- SAM 3 기억 디코더를 c_ini 기억 하나를 중심으로 하는 별 모양 디코딩으로 미세조정합니다.
- π³ 포인트맵은 세 곳에 씁니다.
  - 주의(attention)의 3D 편향
  - 3D 정체성 검사(Fix A)
  - 시점차가 작은 뷰부터 차례로 푸는 릴레이 디코딩(Fix B)
- G4를 통과하면 넓은 시점차 학습(Fix C)을 더합니다.

**주장 후보.** 관문 결과를 보고 범위를 줄입니다.

| # | 주장 | 근거로 쓸 데이터 |
|---|---|---|
| C1 | 같은 SAM 3 위에서, 뷰를 동영상처럼 잇는 전파(G0)보다 낫다 | MUVOD(장면을 보류한 5-fold), ScanNet++, CROOM 새 정답 |

- 지금 MUVOD 키프레임 이득은 G0 대비 J&F +0.018(A-3, `stage1/docs/results-baseline-fix.md:40`)로 작습니다. 현재 프리셋은 0.9174이고 G0은 0.897입니다.
- **TCSVT 결론과 맞춰야 합니다.**
  - TCSVT는 π³ 같은 명시적 3D 경로가 *학습 없는 시드 생성기*로는 이득이 없다고 결론 냈습니다(`tcsvt-submitted:paper/main.tex` 1348–1355행).
  - ICCV는 *학습한 디코더 안에서 쓰는 기하*를 다룹니다.
  - 이 차이는 C4가 수치로 보여야 합니다.
  - C4에서 기하 몫이 0이면 서사를 C1·C3 중심의 "학습형 SAM 3 기억 전이"로 바꿉니다. 그때 π³는 정체성 검사에만 남깁니다.

## 3. 작업 묶음

### WP1 링 일반화 수정 (S1-E15, S1-E17)

**진단.** T06 900번 기준이며, 서술일 뿐입니다. T06은 이미 여러 번 본 개발 집합입니다.
- 무너진 원인은 π³ 오류가 아니라 **정체성 바뀜**입니다.
  - 먼 절반 113쌍 가운데 28쌍이 다른 사람을 잡았습니다. 사슬은 1쌍입니다.
  - π³ 3D 위치는 맞습니다. 평가 가능한 182쌍 중 180쌍에서 가장 가까운 사람이 정답입니다.
- MUVOD의 c_ini → 카메라 시점 범위를 벗어났습니다(2026-10-20 정정, S1-E15 U4).
  - MUVOD에서 c_ini → 카메라 시점차는 최대 약 58°입니다(58.12°, CBABasketball 키프레임).
  - 학습 범위는 이보다 넓습니다. 학습은 주석 카메라 3대의 모든 순서쌍을 쓰므로(`geomem/data.py` `enumerate_samples`) 감독되는 쌍은 약 89.7°(Blocks)까지 갑니다. 초판의 "학습 쌍 최대 약 58°"는 틀렸습니다. 그래서 붕괴는 각도만의 문제가 아닐 수 있습니다(닮은 사람, 뒷모습).
  - T06에서는 58 %의 뷰가 60°를 넘습니다.
  - 붕괴는 47.8°와 54.6° 사이에서 시작합니다(장면 기준점, C0). S1-E15의 객체 기준점으로는 C0가 65.3°와 74.1° 사이, 라운드 1이 53.1°와 65.3° 사이입니다.
- 학습된 3D 편향이 약합니다. 차이가 약 1.1 nat입니다.
- `reproj` 게이트가 먼 시점의 맞는 마스크를 71–83 % 거절합니다.
- 시뮬레이션 결과입니다.
  - 정체성 검사 후 사슬로 대체하면 J가 0.742에서 0.893이 됩니다.
  - 공동 가시성 경로를 더하면 0.914–0.928입니다.
  - 사슬만 쓰면 0.941입니다.

**할 일.**
1. **D1–D5 진단**(0.5 GPU-h 미만):
   - D1: 라운드 1 마스크를 저장해, 바뀜이 라운드 1에서 오는지 2에서 오는지 봅니다.
   - D2: 학습하지 않은 별 디코딩
   - D3: 편향을 0으로 둔 디코딩
   - D4: `--xcl none`
   - D5: 17장면 체크포인트와 fold 2 규칙 비교
2. **S1-E15 등록**: Fix A와 Fix B를 함께 넣습니다. 학습은 없습니다.
   - Fix A: 3D 정체성 검사. θ_s 밖 먼 뷰에서 `reproj` 대신 신뢰 신호로 씁니다. 별 뷰는 `reproj`를 그대로 둡니다(2026-10-20 개정: S1-E15 주 범위 R, U2. 모든 곳에서 바꾸는 범위 G는 측정 팔).
   - Fix B: θ_s를 넘는 뷰를 시점차 순으로 릴레이 디코딩합니다. 기억은 c_ini와, 검사를 통과한 이웃 최대 3개입니다.
   - 상수는 DEV-A·DEV-A′와 T06 개발 집합에서만 고릅니다. DEV-B·DEV-B′는 한 번만 봅니다(DEV-A′/B′는 2026-10-20 규약 개정).
   - 검사에 걸린 객체를 사슬 마스크로 바꾸는 방식은 절제 팔로만 둡니다. 사슬은 TCSVT 1단계이기 때문입니다.
3. **S1-E17 등록**: Fix C(넓은 시점차 학습)입니다.
   - 60–180° 쌍과 릴레이식 기억으로 학습합니다. 학습에 이미 약 89.7°까지의 쌍이 있으므로 이 전제는 S1-E17 등록 전에 다시 봅니다(2026-10-20).
   - 데이터는 ScanNet++ 학습 분할을 먼저 씁니다(WP3과 공유). 사람 데이터는 결정 D5로 정합니다.
   - 시점차를 아는 편향은 선택 사항입니다.
4. **외부 장면 체크포인트 규칙을 먼저 고정합니다**(결정 D6). 외부 시험 점수를 보고 고르지 않습니다.
