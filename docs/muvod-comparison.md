# MUVOD 벤치마크 비교 — 채택 구성 대 공개 기준선

**프로젝트 최초의 외부 비교입니다.** 지금까지의 모든 수치는 우리가 만든 변형끼리의 비교였고,
"좋아졌다"는 말의 기준점이 우리 안에 있었습니다. 이 문서는 데이터셋을 만든 쪽이 논문에 실은
기존 방법의 점수와 나란히 놓은 결과입니다.

- 프로토콜과 c_ini 확정 근거: [muvod-protocol.md](muvod-protocol.md)
- 기준선: MUVOD 논문(arXiv:2507.07519) Table III·IV, XMem을 공간축·시간축에 함께 적용한 방법
- 우리 열: `SegMaskSam3XW1GPS4M` — 채택 구성(`--xview-window 1 --xview-gate --xview-ptr
  --xview-tpos-shift 4 --track-cams closure`)을 **장면별 c_ini에서 시딩**해 17개 장면 전부 재실행
- 재현: `python3 eval/report_jf.py --raw jf_muvod.json --muvod`

## 2. 이 비교가 공정한지 — 확인한 것들

이 정도 차이가 나오면 프로토콜을 잘못 맞췄을 가능성부터 의심해야 합니다. 확인 가능한 전제를 전부 대조했습니다.

| 확인 | 결과 |
|---|---|
| 채점 카메라 | 배포된 주석에 들어 있는 카메라와 정확히 같은 셋 (c_ini + 2대) |
| 프레임 | 17개 장면 전부 카메라당 21장, 프레임 번호 구간도 배포 색인의 주석 오프셋과 일치 |
| 객체 수 | 17개 전부 배포 색인의 인스턴스 수와 일치 |
| 정답 마스크 | 배포본과 바이트 동일 (MATF만 카메라 폴더 이름이 다르고 내용은 같음) |
| c_ini | 논문 표의 basic=complete 패턴을 **17개 전부** 재현 (`eval/muvod_census.py`) |
| 뷰 수 | 16개 일치. Welder만 색인 41 대 디스크 46이나, 이 장면은 세션 0\~3만 돌아 결과에 무관 |

**논문이 정하지 않아 우리가 택한 두 가지**도 크기를 재 두었습니다.

- **c_ini의 주어진 첫 프레임을 채점하는가.** 우리는 21장 전부를 씁니다. 그 한 프레임을 빼면
  89.82 → 89.76으로 **0.06점** 줄어듭니다. 결론이 바뀌는 크기가 아닙니다.
- **카메라에 아예 없는 객체.** 카메라마다 그 카메라 정답에 실제로 나오는 객체만 셉니다. 대안(없는
  객체에 빈 예측으로 만점을 주는 것)은 점수를 부풀리므로 택하지 않았습니다.

## 3. 유일하게 지는 장면 — Welder

Welder는 −1.2입니다. 원인은 **가장 먼 카메라에서의 객체 소실**입니다.

| 카메라 | 뷰 인덱스 | 객체 수 | 평균 J&F | 최악 객체 |
|---|---|---|---|---|
| camera_0001 (c_ini) | 0 | 16 | 0.922 | 5: 0.65 |
| camera_0003 | 2 | 16 | 0.848 | 8: 0.54, 4: 0.56 |
| camera_0004 | 3 | 15 | **0.749** | **14: 0.02, 8: 0.02** |

c_ini에서 먼 camera_0004에서 객체 두 개가 사실상 전멸(0.02)했고, 그 둘이 카메라 평균을 0.85 수준에서
0.749로 끌어내립니다. 같은 형태가 AlexaMeadeExhibit의 camera_0004(객체 셋이 0.00)에서도 보입니다.
이는 이미 진단해 둔 **퇴화 시드 문제**(P5)와 같은 실패 양상입니다 — [raw/seed_census.md](raw/seed_census.md)는
Welder의 복구 여지를 0.8437 → 0.8839로 추정했습니다. 즉 이 장면의 열세는 방법의 한계가 아니라
**아직 구현하지 않은 복구 단계가 비어 있어서**일 가능성이 큽니다.

## 4. 유의할 점

- 이 비교는 **방법 대 방법**이지 동일 조건 실험이 아닙니다. 우리는 SAM 3 기반이고 기준선은 XMem이며,
  기초 모델의 세대 차이가 있습니다. 큰 차이의 상당 부분은 거기서 옵니다.
- 우리 구성 안에서 교차시점 메모리 자체가 기여하는 몫은 훨씬 작습니다(사전 등록 기준 미달, +0.002 수준).
  두 이야기를 섞지 마십시오 — 벤치마크 우위는 SAM 3 기반 파이프라인 전체의 것이고, 공간축 메모리의
  순효과는 별도로 측정해 [phase2-control.md](phase2-control.md)·[phase3-conditioning.md](phase3-conditioning.md)에
  적어 두었습니다.
- 기준선 수치는 논문에서 옮겨 적은 것이고, 우리가 XMem을 다시 돌린 것이 아닙니다.
