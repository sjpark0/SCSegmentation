1단계(시점 전파)는 대조군과 헤드라인이 같으므로 t=0 시드는 P1-C = P1-H(감시값 Z1). P2는 1단계만 보면 되므로 프레임 2장만 돌립니다.

**P2 프롬프트 마스크 만드는 규칙** (`plenoptic/prompt_seed.py`, 동결 `SCSam3/sam3` 패키지의 이미지 모델 그대로):
- 텍스트: `Sam3Processor(confidence_threshold=0.5)`, `set_text_prompt("person")` → 인스턴스 마스크 집합. 정답 id 붙이기: 기준 카메라 t=0 정답과 IoU로 헝가리안 매칭, IoU ≥ 0.5인 것만 짝으로 인정. 짝 못 지은 인스턴스는 버리고(개수 보고), 짝 못 지은 사람은 빈 시드(보고). 겹치는 화소는 점수 높은 인스턴스가 가짐.
- 포인트: 사람마다 정답 마스크의 거리 변환 최대점(마스크 안에서 가장 안쪽 화소) 1개, 양성. `enable_inst_interactivity=True` 이미지 모델, `multimask_output=True`에서 예측 점수 최대 마스크. 정답은 **점 위치를 정하는 데만** 쓰입니다(표준 1-click 프로토콜).
- 두 경우 모두 기준 카메라 프롬프트 마스크 자체의 정답 대비 J를 보고합니다.

## 2. 읽는 값

정의: 쌍 = (카메라, 사람). 비기준 쌍 31 × 6 = 186, 그중 정답 있는 쌍 184, 정답 없는 행 2(`cam_12` p5, `cam_15` p3). J = 예측∩정답/예측∪정답 (`eval/eval_jf.py` 그대로, t = 0 프레임만 정답이 있으므로 그 프레임만 채점됨). 링 거리 d = min(|k − 6|, 32 − |k − 6|) ∈ 1..16.

| 값 | 정의 |
|---|---|
| **Q1** 1단계 평균 J | P1-C t=0, 정답 있는 184쌍 평균 |
| **Q2** 거리 곡선 | d별 평균 J (각 d에 카메라 2대 × 6명, d=16은 1대) |
| **Q3** 실패율 | J < 0.5인 쌍 비율, 빈 예측 쌍 수, 정답 없는 2행에 예측이 있는 수(환각) |
| **Q4** 프롬프트 손실 | Q1(P2-T) − Q1(P1-C), Q1(P2-P) − Q1(P1-C); 기준 카메라 프롬프트 마스크의 J |
| **Q5** MUVOD식 장면 점수 | t=0 J&F를 객체 → 카메라 → 장면 순으로 평균 (참고용, 벤치마크와의 크기 비교) |
| **Q6** 사건 감사 (P3, 서술) | 아래 규칙 |

**Q6 사건 규칙** (정답 없음, 마스크 면적만): 쌍마다 t=0 면적 A₀(대조군·헤드라인 공통). 구성 X에서 "소실 구간" = 면적 < 0.1·A₀인 연속 ≥ 3프레임. 그 구간 안에서 다른 구성 Y가 ≥ 2프레임에서 면적 ≥ 0.5·A₀이면 "갈림 사건(X 잃고 Y 유지)". 양방향 모두 셉니다. 사건마다 저자가 프레임을 보고 (i) 원인 — 가림 / 화면 이탈 / 추적 실패, (ii) Y가 유지한 마스크가 그 사람 위에 있는지 — 를 표시합니다. 자동 규칙은 후보를 뽑을 뿐이고 판단은 사람이 합니다. **관문 없음.**

## 4. 감시값 (배관 오류 검출, 하나라도 실패하면 결과를 쓰지 않고 원인부터)

- **Z1** P1-C와 P1-H의 t=0 PNG가 32대 × 6명 전부 바이트 동일.
- **Z2** 기준 카메라 t=0 PNG == 시드(정답 또는 프롬프트 마스크) 바이트 동일 (`--frame0-seed`).
- **Z3** 매니페스트 `provenance.argv`가 위 표와 일치, `xview_window`·`xview_mode` 등 실제 값이 명령과 일치.
- **Z4** 변형 장면(P2)의 `Video`가 공유본과 같은 파일(심링크 대상 확인), `Mask`는 `cam_06`만 다름.

## 6. 하지 않는 것

- 추가 프레임 정답 제작(사용자 결정 2026-09-16). 따라서 2단계의 정량 점수는 없고 Q6은 서술입니다.
- 텍스트/포인트 시드로 2단계 전체를 돌리는 것(P2는 1단계만). 필요하면 별도 등록.
- 규칙·임계값(0.1·A₀, 0.5·A₀, 3프레임, IoU 0.5) 변경. 바꾸려면 사용자 결정 + 재등록.
