## 5. 논문에 쓰는 문장 (§VIII "Beyond the Benchmark")

1. 32대 링, 여섯 사람, 첫 프레임 손 정답, 자체 촬영·비공개, 시연.
2. 정답 마스크 → 텍스트 한 단어로 바꿔도 1단계가 같다(−0.002); 이건 개념 프롬프트를 받는 SAM 3라서 가능하고 XMem·SAM 2는 못 한다. ID 매칭은 채점용.
3. 클릭 하나는 부분을 고른다(0.42 → 0.36) — 텍스트가 모호성을 푼다.
4. 링 거리 무관(예측 실패를 그대로 씀).
5. 가림 사건 1/0, 15쌍은 둘 다 잃음 — 한 사건은 시연이지 측정이 아님.
