## 3. E0′ — 0.951 천장의 정체

**실제 체인(동결 패키지에서 확정; 파일:줄은 `MVSeed/ceiling_roundtrip.py` docstring).** 마스크 프롬프트 → `add_new_mask`가 **1152**(288×4)로 리사이즈(사전 등록의 "1008"은 오기; 이 단계는 무손실) → `_use_mask_as_output`으로 비디오 해상도 ±1024 로짓(SAM 디코더는 객체 포인터용으로만 돌고 그 로짓은 버려짐) → `_consolidate_temp_output_across_obj`에서 **288×288로 bilinear antialias 다운샘플(유일한 손실, 종횡비 미보존)** → 프롬프트 프레임은 재추론 없이 저장된 288 로짓을 그대로 냄 → bilinear 업샘플 → `>0`. non-overlap·fill-hole은 이 구성에서 무동작. c_ini는 이 왕복을 **두 번**(1단계 시드, 2단계 재프롬프트) 지납니다.

재현과 측정의 차이 −4×10⁻⁷(398쌍 중 367쌍 픽셀 동일, 31쌍은 1~4 px 반올림 차). **판독: "artefact"**(등록 규칙 ±0.02 안). 크기별 2회 왕복 J: <2k px **0.822**(n 36), 2k~10k 0.924(94), ≥10k 0.978(268). 리그 무관(핀홀 0.951, 반구 0.952).

## 6. 이것이 계획을 어떻게 바꾸는가

1. **G1 = `reverse`만** SeedVote 후보로. `ref_outward`는 버림.
2. **분모 갱신**: 이후 관문의 F0 = 41(핀홀∧≥2k 16), N0 = 623. E2 관문의 "≥2,000 px 22쌍 중 ≥12"는 비율 55%로 등록돼 있으므로 F0∩≥2k = 19쌍 기준 **≥11**, E4의 "≥45%"는 16쌍 기준 **≥8**.
3. **새 열린 항목 — 해상도 인공물**: 시드 J의 상한이 1회 왕복 0.970, 2회 0.951이고 작은 객체는 0.82. 계획 밖(2단계 입구)이었지만 1단계 출력에도 걸리므로, `--low-res` what-if(GPU 0)로 "격자를 288→576으로 올리면 왕복 J가 얼마나 회복되는가"를 먼저 재고, 모델 변경 없이 되는 경로(프롬프트를 원해상도로 유지하는 출력 경로)가 있는지 별도 등록 대상으로 둡니다.
4. 대리 지표 확인: 원시 시드 J → 최종 J R² 0.922 — E6 판정을 원시 시드 J로 하는 것이 정당합니다.
