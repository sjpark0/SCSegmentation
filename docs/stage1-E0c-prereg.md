# S1-E0‴ 사전 등록 — **격자 천장**: 288 격자가 남은 9점 중 몇 점인가

> 2026-09-12. [stage1-E0.md](stage1-E0.md) §6 **열린 항목 3번**("`--low-res` what-if(GPU 0)로 격자를 288→576으로 올리면 왕복 J가 얼마나 회복되는가를 먼저 재고")을 실행합니다. 층: 탐색, **관문 없음**(진단). GPU 0.
> 사용자 결정 2026-09-12: CVPR 가능성 평가에서 이 측정이 가장 값싸고 판을 바꿀 수 있다고 판단돼 우선 실행.

## 1. 이미 본 것 (정직하게 먼저 밝힙니다)

**오늘 이 문서를 쓰기 전에 기준 카메라 398쌍의 사다리를 이미 돌렸습니다.** 따라서 아래 표는 사전 등록된 예측이 아니라 **관측된 사실**이고, §4의 예측은 이 정보를 가진 상태에서 세운 것입니다.

| 격자 | 시드 천장 `J_rt1` | 프레임 0 천장 `J_rt2` | <2k px `J_rt2` |
|---|---|---|---|
| **288 (현행 체인)** | 0.9700 | **0.9511** | **0.8219** |
| **576** | 0.9934 | **0.9896** | **0.9639** |
| 1008 | 0.9987 | 0.9984 | 0.9954 |

- 288 재구성은 본류 프레임 0과 **367/398 쌍 픽셀 동일**, 측정 J − 재구성 J 평균 **−0.00000** → 사다리가 실제 체인과 같다는 확인(S1-E0′ 등록 판독 "artefact" 재현).
- 격자 288은 `sam3_tracker_base.py:130`의 `low_res_mask_size = 1008 // 14 * 4`이고 **동결 패키지 안**입니다.

## 2. 아직 보지 않은 것 — 이 등록의 대상

기준 카메라 398쌍은 **프레임 0**의, 그것도 **정답을 프롬프트로 받은** 카메라입니다. 정작 알고 싶은 것은 [error-budget.md](error-budget.md)가 남은 **8.985점 중 7.87점**이라고 한 **정상 쌍 1,051개 × 21프레임**에서 격자가 몇 점을 먹는가입니다. 그 값은 측정된 적이 없습니다.

## 3. 방법 (상수는 실행 전에 고정)

`MVSeed/grid_ceiling.py`(신규), CPU만.

1. **모집단**: 17장면 × 주석 카메라 3대 × MUVOD **basic** 객체 × **21프레임** 전부, 정답이 비어 있지 않은 (카메라, 객체, 프레임). 기준 카메라도 포함하되 기준/비기준을 나눠 보고합니다.
2. **천장 마스크**: 각 프레임의 정답 마스크를 `MVSeed/ceiling_roundtrip.py`의 `resample(mask, grid)`(±1024 로짓 → 안티에일리어싱 쌍선형 축소 → 쌍선형 확대 → >0)에 한 번 통과시키고, 장면의 객체를 **객체 id 오름차순**으로 `resolve_overlaps`에 넣습니다. 이것이 **그 격자에서 어떤 예측도 넘을 수 없는 상한**입니다.
3. **지표**: `eval/eval_jf.py`의 `db_eval_iou`(J)와 `db_eval_boundary`(F, `bound_th = 0.008`, 디스크 구조요소)를 **그대로 import**해 씁니다. 채점 코드는 수정하지 않습니다.
4. **집계**: MUVOD J&F³ — 프레임 평균 → 카메라별 객체 평균 → 주석 3대 평균 → 17장면 평균.
5. **격자**: **288(현행) · 576 · 1008**. 격자당 "구조적으로 불가능한 몫" = 100 − 천장 J&F³.
6. 대조: 현행 헤드라인 **91.015**와 오차 예산의 총 격차 **8.985점**.

## 4. 판정 규칙 — 없음(진단). 읽기 규칙만 고정

- 이 실험은 **어떤 것도 채택·폐기하지 않습니다.** 산출물은 "8.985점 중 격자 몫 X점"이라는 숫자 하나와 그 크기별·리그별 분해입니다.
- **읽기 규칙(고정)**: 288 격자 몫이 **8.985점의 40% 이상(≥3.6점)** 이면 "유효 해상도가 남은 오차의 지배적 단일 원인"이라고 적습니다. **20% 미만(<1.8점)** 이면 "격자는 부차적이고 크롭 추적의 이득은 해상도 법칙으로 설명되지 않는다"고 적습니다. 그 사이면 "상당하지만 지배적이지 않음"입니다.
- 이 세 문장 중 어느 것이 참인지에 따라 논문의 축과 학회 선택이 달라지므로, **문장을 지금 고정**합니다.

## 5. 예측

1. **288 격자 천장 J&F³ = 94\~96** → 불가능 몫 **4\~6점** (8.985 중). 근거: 기준 카메라 rt1 0.970이고 프레임 ≥1은 왕복 1회에 해당.
2. **576 천장 98.5\~99.5** → 불가능 몫 0.5\~1.5점.
3. **<2,000 px 객체의 288 천장이 85 미만**.
4. **천장에서도 F > J** (측정 헤드라인이 J 87.3 / F 94.8인 것과 같은 방향).
5. **기준/비기준 천장 차이 < 0.01** — 격자는 카메라를 가리지 않으므로.
6. 읽기 규칙 판정: **"지배적 단일 원인"(≥3.6점) 쪽**.
