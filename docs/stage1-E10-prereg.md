## 1. 가설과 손잡이

SAM 3 추적기의 마스크 로짓 격자는 `low_res_mask_size = 1008 // 14 × 4 = 288`로 디코더 구조가 정합니다(`sam3_tracker_base.py:130`). 1단계의 최종 마스크는 288 격자 → 1008 쌍선형 → 원본 해상도 쌍선형 → 0 문턱입니다.
**가설**: 같은 체크포인트·같은 기억 집합으로 물체 주변을 2배 확대한 크롭을 한 번 더 디코딩하면 물체 위의 유효 격자가 576이 되고, 좋은 시드의 띠 빈틈 가운데 격자 몫(약 1/4)을 학습 없이 되찾을 수 있다.
**손잡이**: 디코딩 경로만(라운드 2 뒤의 세 번째 패스). 학습·체크포인트·라운드 1·게이트·기억 인코딩은 그대로.

이 패스가 겨냥하는 것은 **한 격자 칸(원본 7~10 px) 안의 경계**뿐입니다. 그래서 크롭 결과는 라운드 2 마스크의 경계 띠 안에서만 쓰고(§2 붙이기 규칙), 띠 밖의 판단(범위·존재·다른 객체)은 라운드 2가 그대로 가집니다 — seedfail §4(IoU 게이트로 통째 바꾸기는 0.95에서도 손해)와 E9(부재·IoU 뒤집힘이 큰 손실의 전부)의 교훈.

## 2. 팔 (네 구성; C1·C2가 처리, C3는 대조)

| 팔 | 프리셋 / 결과 폴더 | 내용 |
|---|---|---|
| C0 | `geoset_rep` / `geoset_pred_ft_rep_e8` (채택, E9의 D0) | 기저. 같은 체인에서 다시 채점 |
| C1 | `geoset_rep_z2` / `geoset_pred_ft_rep_z2_e10` | C0 + 크롭 확대 패스(아래), 어텐션은 손대지 않음(크롭 격자에 상대적인 RoPE = 격자 좌표 그대로) |

| C3 | (후처리) / `geoset_pred_ft_rep_gf_e10` | 대조: C0 PNG를 회색조 안내 필터(He et al., 반경 r = 띠 폭, eps 0.01, 문턱 0.5)로 다듬되 **같은 띠·같은 보존 규칙**으로 붙임. 모델 패스 없음, 호스트 CPU. 채택 집합에 들지 않음 — C1의 이득이 "모델 수준"인지 "색 경계에 맞추기"인지 가르는 눈금 |

**크롭 확대 패스(C1·C2 공통, 라운드 2 뒤, 장면·카메라·객체마다)** — 상수는 전부 여기서 고정:

1. 후보 = 라운드 2가 비어 있지 않은 마스크를 낸 (대상 카메라, 객체). 빈 마스크는 건드리지 않음(쓰인 (cam, obj) 집합 불변).
2. 창: 이미지 종횡비의 고정 크기 **(H/2, W/2)** 창을 라운드 2 마스크의 경계 상자 중심에 두고 이미지 안으로 밀어 넣음. 상자 높이·너비 × **1.2**가 창에 들어가지 않으면 **건너뜀**(skip; 마스크 그대로). 종횡비를 유지하므로 1008 늘림이 축마다 정확히 2배: 크롭의 288 격자 한 칸 = 원본 W/576 × H/576 px.
3. 크롭 이미지는 CLI 로더와 같은 변환(`cv2.imread` BGR 슬라이스 → RGB → 1008×1008 쌍선형 → /255 → −0.5/0.5)을 거쳐 `backbone_features`(conv_s0/s1 포함)로. 기하: 같은 π³ 포인트맵(기준 카메라 좌표계, 같은 장면 스케일)의 창 영역을 작업 해상도에서 잘라 `pool_grid` 72로(창 = 전체 이미지이면 `view_grid`와 동일).
4. 디코딩: 라운드 2의 **같은** `MemorySet`(기준 + 게이트 통과 이웃 기억, 전체 뷰에서 인코딩)을 그 객체 하나로 자른 것(`MemorySet.subset`, B = 1)과 크롭 특징으로 `decode_view` 한 번. C2는 쿼리 RoPE 표만 재매핑: 크롭 칸 (i, j)의 위치 = (x0·72 + (j + 0.5)·ww)/W − 0.5, y도 같게(창 = 전체 이미지이면 정수 격자 = 기존 `freqs_cis`).
5. 붙이기: 크롭 로짓 1008 → 창 크기 쌍선형 → 0 문턱 → 창 위치에 놓은 캔버스. **띠 폭 r = ⌈max(H, W)/288⌉**(1920 → 7, 2048 → 8, 2560 → 9, 2704 → 10 px). `band = dilate(full, r) ∖ erode(full, r)`(정사각 (2r+1) 커널), **final = where(band, canvas, full)**. 띠 밖은 라운드 2 그대로.
6. 보존 규칙(순서대로 첫 규칙): 크롭의 presence ≤ 0 또는 크롭 마스크 비어 있음 → 그대로(kept_absent); IoU(canvas, full) < **0.5** → 그대로(kept_iou; 폭 2r 미만 작은 물체 보호); final 비어 있음 → 그대로(kept_empty); 아니면 채택(accepted). 어떤 쌍도 삭제·재해석·r 넘어 성장하지 않음.
7. 기록: 장면 `zoom_conf.json`(쌍별 창·판정·presence/IoU·변화 화소), RUN.json/MANIFEST `stage1_config`에 계수(n_zoom_candidates/run/skipped_large/kept_*/changed/px_added/px_removed/zoom_seconds).

**변수 아님(사후에 돌리지 않음)**: 객체별 가변 배율, 큰 물체 타일링, 절대 위치 임베딩 재매핑, 자기 어텐션 RoPE 간격, 띠 안 로짓 연성 융합, 창 전체 교체, 다듬은 마스크를 기억으로 되먹임, C3의 반경·eps, 쌍둥이/가로채기 게이트, m·r·τ_z·창 규칙의 어떤 변경도.

## 5. 채택 규칙 (실행 전 고정; E9 §5와 같음)

1. **1단계 관문**(C1·C2 팔별): G1 ΔJ&F > 0 이고 95 % CI 하한 > 0; G2 어떤 장면도 C0 − 0.01 아래 아님. 통과 팔만 2단계. 둘 다 미달이면 **"효과 없음"으로 보고하고 끝냄**(m·r·τ_z·창 규칙·RoPE 변형 추가 없음 — 더 돌리려면 새 등록). C3는 관문 대상이 아님: C3만 통과하면 "색 경계 맞추기가 띠 빈틈을 회수"로 보고하고 후처리 채택은 별도 짧은 등록.
2. **2단계 채택**(E8 §5): basic Δ > 0 이고 95 % CI 하한 > 0; 방어선 어떤 장면도 basic Δ < −1.0 아님; complete Δ ≥ 0.
3. 통과 팔이 둘이면 basic 점 추정이 높은 팔; 동률(< 0.05)이면 **C1**(단순한 쪽). 민감도로 본페로니 98.33 % CI(E9와 같이 3으로 나눔) 병기.
4. 채택되면 헤드라인 프리셋을 그 팔로; E8의 학습 데이터 단서·S2-R6 LOSO +0.387 병기는 그대로.
