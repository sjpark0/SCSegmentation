**공통 레시피(바꾸지 않음)**: focal 20 / dice 1 / IoU-L1 1 / presence 1, α 0.25, γ 2, 원본 해상도 손실; lr GeoBias 1e-3 / 기억 어텐션 1e-5; AdamW wd 0.01; 코사인; clip 1.0; 3 에폭; 프레임 간격 2; seed 0; 객체 ≤ 16; 예측 두 번째 기억 p = 0.5(`memory_rng(seed, step)`), τ 0.7; 디코더 동결; 5 폴드; 학습 파라미터 5 922 321.

**M+ 드롭 규칙(상수 전부 여기서 고정; 모듈 상수, CLI 손잡이 아님)** — CUT_PROB 1.0(C0'는 0.0); CUT_KEEP (0.3, 0.7); CUT_MIN_CELLS 20; CUT_MIN_KEPT 6; 면 {왼쪽, 오른쪽, 위, 아래}.
최적화 단계마다(`memory_rng`와 같은 단계 번호), `load_sample` 뒤·`train_one_step` 전:
1. 단계당 생성기 하나 `g = cut_rng(seed, step) = np.random.default_rng([seed, step, 1])` — `memory_rng(seed, step) = default_rng([seed, step])`과 별개; 공유 rng(객체 부분집합, 기억 동전)는 건드리지 않음.
2. `u = g.random()`; `u < CUT_PROB`이면 자름(동전은 C0'·M+ 모두 뽑음 — 0 < p < 1 후속 팔과 매개변수 공유).
3. 객체 칸: `C_b = avg_pool2d(mask_inputs(ref_masks, 1008), 14)[:, 0] ≥ 0.5`(72×72, 토큰 번호 l = y·72 + x = `_pack_view` 평탄화 순서).
4. 배치 순서대로 n_b = |C_b| ≥ 20인 객체마다: 면 = `g.integers(4)`, 남길 비율 f = `g.uniform(0.3, 0.7)`, k = ⌊(1 − f)·n_b⌋, 좌표 a = x(왼쪽) / −x(오른쪽) / y(위) / −y(아래), a_c = sorted(C_b의 a)[k]; **a(l) < a_c인 모든 칸(객체·배경 모두)을 drop[b, l] = True**. 경계선 동률은 남김(실현 남김 비율 ∈ [f, f + 최대 한 줄/n_b]); 하나도 안 지워지면 "안 자름". 20칸 미만 객체는 아무것도 뽑지 않고 자르지 않음.
5. `MemoryView.drop`([B, 5184] bool)을 `encode_reference` 직후 `ref.views[0]`에 붙임 → 한 단계의 두 읽기 모두(기억 카메라 예측 디코딩, 대상 디코딩), 기억 어텐션 모든 층에 적용. 예측 두 번째 기억에는 드롭 없음(τ 0.7 게이트 그대로). 포인터 토큰은 지우지 않음. **기억 마스크(GT)와 대상 정답은 온전히 둠.** 추론 때는 드롭 없음(drop = None).
6. 기록(모든 팔): `objs`, `mem_coin`, `mem_cam`, `cut`, `n_cut`, `cut_frac`.

학습 기준 라벨맵에서 이 규칙의 실측(`MVSeed/refloss/e12/cut_stats.out`): 적격 행 0.613(기준 GT 화소의 98.3 %), 적격 객체 있는 표본 100 %, 실현 객체 칸 드롭 비율 평균 0.442(p10/50/90 0.28/0.44/0.62), 격자 드롭 비율 평균 0.49, 안 자름 0.6 %. 키프레임 적격 쌍(기준 칸 ≥ 20): 437/664, 좋은 407/605, 실패 30/59, 덜 덮음 15/22.
