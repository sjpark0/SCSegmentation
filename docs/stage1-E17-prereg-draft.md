# S1-E17 사전 등록 초안 — Fix C 넓은 시점차 학습 (G4, 12-23)

> **초안(2026-10-23, 커밋 전 검토용).** 계획 [iccv2027-plan.md](iccv2027-plan.md) §1 3번·§4 G4, 링 진단 [stage1/docs/ring-diagnosis-2026-10-20.md](../stage1/docs/ring-diagnosis-2026-10-20.md) Fix C. 사용자 결정 D5(Fix C 데이터, 11-20)·D1/D2(ScanNet++)·D6(외부 시험 체크포인트)에 걸려 있어 **학습 전 등록 커밋은 그 결정 뒤**에 합니다. 이 초안은 전제 재검토(§1)와 팔·규칙 후보(§2–§5)를 미리 적어 두는 것이며, S1-E16 결과(§1.3)가 나오면 고칩니다.

## 1. 전제 재검토 (등록 전 의무, 계획 2026-10-20)

### 1.1 학습 쌍의 시점차 분포 (S1-E15 Step 0 N2, `scripts/e15/runs/angles.json`)
- MUVOD 학습 표본 = (장면, t, 기준 r, 대상 v), 주석 카메라 3대의 순서쌍 → 17장면 × 11프레임 × 6 = 1 122, 기준 프레임 쌍 68개를 빼면 **1 054쌍**. 객체 기준 시점차 a(r→v): 중앙값 5.5°, 90 % 42.7°, 99 % 83.6°, 최대 89.7°. **45° 초과 9.6 %(약 100쌍), 60° 초과는 그보다 적음(장면 2–3개에 몰림)**.
- 결론: "학습 쌍이 약 90°까지 있다"는 맞지만 **분포가 좁다**(10 % 미만이 45° 초과). Fix C의 전제는 "범위 밖"이 아니라 "넓은 쌍의 표본 수"로 다시 씁니다.
- 예측 기억(두 번째 기억 카메라)은 장면의 모든 카메라에서 균등 추출(`random_memory_camera`)이라 넓은 시점차 기억을 보는 빈도도 낮습니다.

### 1.2 S1-E15가 보인 것
- T06: 릴레이에 신뢰원(Fix A 또는 obj 검사)을 붙이면 디코더 상한(오라클 0.9423)에 닿음. 즉 **먼 뷰 오류는 디코더가 이웃 기억을 받으면 사라지고**, c_ini 기억 하나로 먼 뷰를 바로 푸는 능력(A 단독 0.8054, 라운드 1 0.7154)이 부족한 것.
- Fix C가 겨냥할 양 = **라운드 1(별 디코딩) 먼 뷰 정확도**: T06 먼 절반 J 라운드 1 0.5775, 릴레이 뒤 0.9319. 라운드 1이 오르면 릴레이 의존이 줄고(hop 수·도달 불가 감소), ScanNet++처럼 이웃이 드문 표본에서 이득이 남습니다.

### 1.3 S1-E16에서 볼 것 (10-23 결과 대기)
- NG(기하 없음)가 DEV-A′ 넓은 쌍·T06에서 G와 얼마나 다른지 → 기하 학습이 먼 뷰에 실제로 기여하는지. 기여가 작으면 Fix C는 "시점차 인식 편향" 보다 "넓은 쌍 표본"에 집중합니다.
- 재학습 잡음 σ(시드 3개) → G4의 δ = 0.003 재확인.

## 2. 팔 후보 (학습 팔은 시드 3개, E16과 같은 이유)

| 팔 | 학습 | 디코딩 | 집합 |
|---|---|---|---|
| **C-ov** (MUVOD만, 데이터 추가 없음) | geoset_pred_ft 레시피 + **넓은 쌍 가중 추출**: 표본 (r, v)의 추출 확률 ∝ 1 + λ·[a(r→v) > 45°](λ는 DEV-A′에서 {2, 4}만 비교) + **릴레이식 기억**: 두 번째 기억 카메라를 a(r→m) < a(r→v)인 카메라에서 추출(확률 ½, 나머지 ½는 현행 균등) | 현행 `geoset_rep_xs_ab`(Fix A+B) | DEV-A·A′(설계), T06(개발), DEV-B·B′(확인 1회) |
| **C-ext** (D5 뒤) | C-ov + 외부 넓은 시점차 데이터(ScanNet++ 학습 분할 SPP-MV 표본, D5에 따라 MOVi-MC-AC) 혼합 비율 1:1(표본 수 기준) | 같음 | 같음 + ScanNet++ DEV |
| **C-ang** (선택, 계획 "시점차 인식 편향") | C-ov + GeoBias에 a(r→v) 입력(각도 구간 임베딩 4개) | 같음 | 같음 |
| C0 | S1-E15 주 팔 | — | 대조 |

- 레시피·예산·시드는 E16과 같습니다(3 epoch, stride 2, 폴드 5). 가중 추출은 epoch당 표본 수를 바꾸지 않습니다(재추출).
- 각도는 입력만으로 계산합니다(c_ini 마스크 + π³, E15 §3.1과 같은 정의). 학습 때 각도 캐시(`angles.json`의 entries)를 그대로 씁니다.

## 3. 상수 선택 (DEV-A·DEV-A′·T06만)
- λ ∈ {2, 4}, 릴레이식 기억 확률 ½ 고정, 각도 문턱 45° 고정(A_E 47.24° 아래 값). 선택 규칙: DEV-A′ 넓은 쌍 ΔJ 최대, 동률이면 DEV-A ΔJ&F CI 하한.
- T06 라운드 1 먼 절반 J(C0 0.5775)와 최종 J_all을 함께 봅니다.

## 4. 확인 규칙 (G4, 계획 §4; DEV-B 디코딩 전에 커밋)
