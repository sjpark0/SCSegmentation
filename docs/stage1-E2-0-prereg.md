# S1-E2-0 사전 등록 — G-det 실현성 스파이크: 동결 SAM 3에서 교차 이미지 예시 검출이 되는가

> 2026-09-10. [stage1-plan.md](stage1-plan.md) §3 G-det·§5 S1-E2-0. 층: 탐색. 결과가 "안 됨"이면 G-det는 폐기되고
> 검출–연결은 G-corr/G-geo/G-gs가 준 위치를 1프레임 세션에 점·박스로 넣는 형태만 남습니다.

## 1. 알려진 사실
동결 패키지의 예시(exemplar) 프롬프트는 **같은 이미지 안**에서만 동작합니다: 박스는 그 프레임의 기하 프롬프트로만 검출기에 가고,
프레임 간 공유 슬롯 `visual_prompt_embed`(`sam3_image.py` `_encode_prompt`)는 채워지지 않으며, 텍스트 없이는 다른 프레임에서
새 검출이 허용되지 않습니다(분석 보고서 반박 검토, [stage1-plan.md](stage1-plan.md) §1.2).

## 2. 시험
패키지를 수정하지 않고(서브클래스/래퍼) 단일 GPU 프로세스 안에서:
1. c_ini 이미지에 정답 객체의 박스를 예시로 주어 `detector._encode_prompt`가 만드는 예시 특징(geo_feats)을 얻는다.
2. 그 특징을 **다른 뷰**의 `visual_prompt_embed` 슬롯에 주입하고, 텍스트 없이 검출이 허용되도록(`allow_new_detections`) 그 뷰에서
   검출기를 돌려 후보 마스크·점수를 얻는다.
3. 측정(정답은 오프라인 측정에만): ① 같은 이미지(c_ini 박스 → c_ini 검출)에서 정답 객체와 IoU>0.8인 후보가 나오는 비율;
   ② c_ini ↔ 인접 주석 카메라의 **정상 쌍 20개**(F0 밖, 정답 면적 ≥2,000 px, 5장면 × 4)에서 정답 마스크와 IoU≥0.5인 후보가
   존재하는 비율(재현율)과 그 후보의 순위·후보 수.

## 3. 살해 기준(고정)
- ① < 0.8 → 예시 경로 자체가 재현되지 않음 → G-det 폐기.
- ① ≥ 0.8이고 ② < 0.7 → 교차 주입은 학습 분포 밖 → G-det 폐기.
- 둘 다 통과 → S1-E2(F0 관문)로 진행.

## 4. 예측
①은 0.9 이상(같은 이미지 예시는 SAM 3의 학습 과제). ②는 **0.3~0.6** — 예시 토큰이 그 이미지의 특징 격자에서 ROI-align된 것이라
다른 뷰의 격자와는 정합이 약할 것(추정). 즉 폐기 쪽이 더 유력.
