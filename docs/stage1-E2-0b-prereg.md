# S1-E2-0′ 사전 등록 — 예시 토큰을 박스가 아니라 **마스크**로 만들면 어떻게 되는가

> 2026-09-10. [stage1-E2-0.md](stage1-E2-0.md)의 후속. 사용자 지적: "박스 안에 객체가 작은 비율로 있으면 박스 예시는 배경을
> 같이 담는다 — 입력은 마스크여야 한다." 이것은 **설계 변경**(예시 토큰의 정의)이지 규칙 변경이 아닙니다. 모집단(같은 40쌍)과
> 살해 기준(①≥0.8, ②≥0.7)은 E2-0 그대로 둡니다. 층: 탐색.

## 1. 알려진 사실 (E2-0 결과와 코드)
- 동결 SAM 3 **검출기**의 프롬프트 인코더(`SequenceGeometryEncoder`, `model_builder.py` 268~283행)는 점·박스만 받도록 빌드됩니다
  (`mask_encoder=None`). 2단계에서 쓴 마스크 입력 경로(`add_new_mask` → `_use_mask_as_output`)는 **트래커**(다른 망, 다른 가중치)의
  것이라 검출기에 그대로 옮길 수 없습니다.
- 박스 예시 토큰 = (a) 특징 격자(72×72, 1008 입력)에서 박스를 **7×7 ROI-align**한 뒤 7×7 합성곱 → 1벡터(외형)
  + (b) 박스 좌표의 직접 투영 + (c) 박스 위치 부호화, 여기에 라벨 임베딩; 그 뒤 CLS 토큰과 함께 교차어텐션 3층이 **이미지 전체**
  특징을 참조합니다(`geometry_encoders.py` `_encode_boxes` 632~681행, `forward` 717~).
- E2-0의 ② 실패 7쌍(등록 3 + 핀홀 4) 중 5쌍은 c_ini 박스 채움 비율(정답 화소 / 박스 면적)이 **0.32 이하**(FacePaint 2: 0.32, Dog 3: 0.31,
  Exhibit 5: 0.27, Barn 1: 0.11, Blocks 6: 0.24); 나머지는 MATF 5(0.48), Frog 3(0.69). 성공 33쌍의 채움 비율 중앙값은 0.55.
  즉 "배경이 섞인 토큰"이 실패와 같이 갑니다(관찰; 인과는 이 실험이 잼).

## 2. 시험 — 팔(같은 40쌍, 같은 후보 규칙 prob>0.5·NMS 0.1)
예시 토큰의 외형 성분 (a)만 바꾸고 (b)(c)·CLS·교차어텐션은 그대로 둡니다. 마스크는 c_ini 정답 마스크(원본 해상도)를 특징 격자
(72×72)로 **면적 평균 축소**한 덮임 비율 m∈[0,1]입니다(프레임은 1008×1008로 그냥 리사이즈되므로 전체 프레임 축소가 일치).

| 팔 | 정의 | 층 |
|---|---|---|
| `box` | E2-0의 `same`/`slot`/`base` 재계산 (E2-0 수치와 쌍별 일치를 확인 — 결정론 점검) | 대조 |
| **`mask`** | ROI-align(feats·m) ÷ ROI-align(m) — 각 7×7 칸에서 **마스크 안 특징만의 평균**; 덮임 < 0.05인 칸은 객체 전체의 덮임 가중 평균 특징으로 채움. 박스·좌표·CLS·교차어텐션 불변 | **등록** |
| `mask0` | ROI-align(feats·m), 정규화 없음 — "마스크 밖을 0으로" 그대로. 채움 비율이 작을수록 토큰 크기가 줄어드는 소박한 형태 | 탐색 |
| `maskimg` | 특징 격자 자체를 마스크 밖에서 0으로 만든 뒤 인코더에 투입 — 풀링과 교차어텐션 메모리 모두 객체 칸만 봄 | 탐색 |

구현은 E2-0과 같이 **인스턴스 래핑**(`geometry_encoder._encode_boxes`를 인스턴스에서 그림자 처리; 패키지 무수정).
구현 관문(과학 기준 아님): m≡1이면 `mask` 토큰이 박스 토큰과 일치해야 함(allclose, 1e-5) — 시작 시 자체 검사, 실패하면 중단.

측정은 E2-0 §2와 동일: ① 같은 이미지(c_ini 예시 → c_ini 검출) IoU>0.8 후보 비율, ② 다른 뷰 IoU≥0.5 후보 존재 비율·순위·후보 수.
추가 기록: 쌍별 채움 비율, `mask`−`box`의 후보 최고 IoU 차(쌍 대응), 채움 비율 < 0.5 / ≥ 0.5 층별 ② 적중.

## 3. 판정 규칙(고정) — **`mask` 팔 하나**로 판정
- ① ≥ 0.8 이고 ② ≥ 0.7 → G-det 진행(S1-E2), 예시 토큰 정의 = **마스크 예시**.
- ① < 0.8 → E2-0의 결정 지점이 그대로 남음(① 모집단 문제는 사용자 결정); ②만으로 진행하지 않음.
- ① ≥ 0.8 이고 ② < 0.7 → 마스크 예시 폐기, E2-0 기록(박스) 유지.
- 탐색 팔(`mask0`, `maskimg`)은 보고만; 판정에 쓰지 않음.

## 4. 예측
- ① `mask`: **15~17/20**. E2-0의 ① 실패 5쌍 중 3쌍(Dog 3·4, Exhibit 5)은 검출기의 분할 단위가 정답과 다른 초대형 배경 영역이라
  마스크로 고쳐지지 않을 것; Welder 5·Exhibit 3(0.73·0.77)은 오를 수 있음.
- ② `mask`: **17~19/20**(박스 17/20 이상). 되찾는 쌍은 채움 비율 0.32 이하인 것(FacePaint 2, Dog 3, Exhibit 5) 쪽; 핀홀 보조에서도 16→17~19.
- `mask`−`box` 후보 최고 IoU 이득은 채움 비율 < 0.5 층에 집중(≥0.5 층은 ±0.03 이내).
- `mask0`은 채움 비율이 작은 쌍에서 `mask`보다 나쁨(토큰 크기 축소). `maskimg`은 `mask` 이하(문맥 상실) — 자신 없음.
