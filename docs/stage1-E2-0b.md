## 2. 판정 — 등록 규칙대로 **`mask` 팔 ① 0.05 < 0.8 → 마스크 예시 폐기**, E2-0의 박스 기록과 결정 지점이 그대로 남음

**예측 대조**(모두 빗나감): ① mask "15~17/20" ✘ (1/20) · ② mask "17~19/20" ✘ (9/20) · "이득은 채움 <0.5에 집중" ✘ (손실이 전 층에서 나고

## 3. 해석 — 박스 토큰의 뜻에는 **박스 안의 공간 배치**가 들어 있다
- 박스 예시 토큰의 외형 성분은 7×7 ROI-align 격자를 **7×7 합성곱** 하나로 접은 벡터입니다. 이 합성곱은 학습 때 항상 "가운데 객체 + 가장자리 배경"의 격자를 봤으므로, 그 배치 자체가 토큰의 일부입니다. 배경 칸을 객체 평균으로 채우거나(`mask`) 0으로 두면(`mask0`) 격자의 배치가 사라져 **같은 이미지에서도** 토큰이 "이 객체"를 뜻하지 못합니다(① 15→1). 2단계의 마스크 입력은 **트래커**의 마스크 인코더가 학습된 경로라 같은 논리가 성립하지 않습니다.
- `maskimg`는 격자 배치를 유지합니다(마스크 밖 0은 사전 LayerNorm을 지나 상수가 됨) — 그래서 박스와 거의 같습니다(② 16 vs 17). 즉 교차어텐션이 보는 배경 문맥은 거의 기여하지 않고, **배경을 지워도 채움 비율이 낮은 쌍의 실패는 안 고쳐집니다**(채움 <0.5 적중 7→7). E2-0에서 관찰된 "낮은 채움 ↔ ② 실패"의 상관은 배경 오염이 원인이 아니라, 7×7 격자에서 가는 객체가 차지하는 칸이 적은 것·개념 모호성 쪽으로 보입니다(추정).
- 진단: `mask` 팔에서도 200개 쿼리 중 최고 IoU는 여전히 높은 쌍이 많습니다(예: FacePaint 2 0.76(58위), Exhibit 4 0.85(65위)). 토큰이 객체를 아예 못 찾는 게 아니라, 프롬프트 평균과 쿼리의 내적으로 점수를 주는 **점수기**가 마스크 토큰에는 낮은 확률을 준다는 뜻입니다 — 분포 밖 토큰의 전형.
- 결론: 동결 검출기의 예시 입력은 **박스**(학습 형식)여야 합니다. "마스크를 예시로" 하려면 검출기에 마스크 인코더를 붙여 학습하거나 프롬프트 인코더를 미세조정해야 하며, 이는 현재 전제(SAM 3 동결)의 밖입니다.

## 4. 남은 결정(E2-0 §4와 동일)
G-det의 예시는 박스로 두고, E2-0의 ① 미달(0.75; 실패 5쌍 중 3쌍이 화면 11~34%의 배경 영역)을 어떻게 볼지가 남습니다: (a) ① 모집단을 "정답이 화면 10% 미만인 객체"로 **재등록**(데이터를 본 뒤의 규칙 변경 → 사용자 결정) 후 S1-E2로 진행, (b) G-det 폐기(검출–연결은 G-corr/G-geo/G-gs 위치 + 1프레임 프롬프트만).

## 6. 보충 진단(09-10, 판정 아님) — "박스 안 10%짜리 객체의 박스 토큰은 나머지 90%를 뜻하지 않는가"
사용자 질문에 답하려고 박스 예시의 **1위 후보**가 무엇을 덮는지 40쌍 전부에서 쟀습니다(`MVSeed/runs/e2_0_box_token_diag.json`; 정답·박스 나머지(박스−정답)·같은 뷰의 다른 라벨 객체와의 IoU, 면적비).
- **같은 이미지**: 채움 비율 ≤0.32인 10쌍 중 **7쌍은 1위 후보 = 정답**(IoU ≥0.81, 박스 나머지와 IoU ≤0.02) — 채움 **8%**(FacePaint 4)·20%(MATF 2)·24%(Breakfast 3, Blocks 6)·27%(Barn 2)·30%(Dog 2)·32%(FacePaint 2) 포함. 40쌍 어디서도 1위 후보가 박스 나머지를 덮지 않음(나머지 IoU 최대 0.35, Dog 4 = 1.28M px 영역). 실패 3쌍은 3.7k px 미소 객체(Barn 1: 후보가 정답의 2배 크기 얼룩)와 초대형 배경 영역(Exhibit 5·Dog 3: 후보가 영역과 이웃 영역을 섞음). 즉 토큰은 외형 풀링만이 아니라 **박스 좌표·범위**(직접 투영 + 위치 부호화)와 전체 이미지 교차어텐션을 담고, 학습 때부터 박스는 늘 배경을 포함했으므로 "이 박스가 꼭 맞는 물체"를 가리킵니다.
- **다른 뷰**: 1위 후보가 다른 라벨 객체를 덮는(IoU ≥0.5) 쌍은 7개 — 초대형 영역이 이웃 영역으로 흐른 것 2쌍(Dog 3 → 영역 7 0.91, Exhibit 5 → 16 0.67), 2k px 미소 객체 대신 큰 이웃이 1위인 것 1쌍(Exhibit 4 → 2 0.92), 나머지 4쌍은 **같은 종류의 다른 개체**입니다(Blocks 5 → 블록 9 0.97, Barn 2 → 3 0.95, MATF 2 → 36 0.93, MATF 3 → 1 0.95; 채움 0.62·0.84에서도). 개념 검출기의 성질("그 개념의 모든 개체")이며, 정답은 대개 2위 후보로 남아 있음(E2-0: 존재 17/20, 1위 13/20). 후보 중 **고르는 단계(연결)**가 위치·기하 신호(SeedVote S2)로 쌍둥이를 갈라야 함.
