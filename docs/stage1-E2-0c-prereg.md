# S1-E2-0″ 사전 등록 — 마스크 정보를 **학습된 프롬프트 경로**로 넣는다: 내부 점 예시 + 음성 박스 예시

> 2026-09-10. [stage1-E2-0b.md](stage1-E2-0b.md)의 후속, 사용자 승인(A). 학습 없는 마스크 토큰(E2-0′)은 박스 토큰의 뜻을 깨뜨려 실패했으므로,
> 이번에는 배포 가중치가 **학습한 경로 그대로** — 점 예시와 양/음성 박스 예시 — 로 마스크 정보를 넣습니다. 인코더 수정 없음, 패키지 무수정.
> 모집단(같은 40쌍)과 살해 기준(①≥0.8, ②≥0.7)은 E2-0 그대로. 층: 탐색.

## 1. 알려진 사실
- 검출기 프롬프트 인코더(`SequenceGeometryEncoder`)는 박스(직접 투영·7×7 ROI·위치 부호화)와 **점**(직접 투영·`grid_sample` 1점 특징·위치 부호화)을
  받고, 라벨 임베딩은 2종(1 = 양성, 0 = 음성)입니다(`geometry_encoders.py` 520~521, 589~630행). 패키지 `add_prompt`도 `box_labels` 0을 받습니다
  (경고 "A negative box is added as a visual prompt", `SCSam3VideoInference.py` 196~197행). 점 경로가 실제로 얼마나 학습됐는지는 **미지**.
- E2-0′ §6 진단: 박스 예시의 교차 뷰 1위 오선택 7쌍 = 같은 종류의 다른 개체 4, 초대형 배경 영역이 이웃 영역으로 흐름 2, 미소 객체 1.
- c_ini 라벨 구조(입력 쪽, 40객체): 모든 객체에 표적 박스와 겹치는 다른 객체가 ≥1개 있고, 대부분은 표적 박스를 **통째로 담는** 바닥·벽·탁자 영역
  (예: FacePaint 10, Dog 4·5·6, Exhibit 5, Breakfast 25, Welder 13, Barn 26, Frog 5, MATF 33, Blocks 8, CBABasketball 22). 내부(경계에서 ≥3 px) 화소는 최소 686(Exhibit 4).

## 2. 팔 (같은 40쌍, 같은 후보 규칙 prob>0.5·NMS 0.1, 텍스트 "visual", 슬롯 주입 동일)
프롬프트는 패키지 형식 그대로(`Prompt(box_embeddings, box_labels, point_embeddings, point_labels)`, 열 우선, 라벨 1/0). 예시 토큰은 이 프롬프트를 c_ini 기하
인코더에 넣어 나온 열(토큰들 + CLS) 전체입니다.

| 팔 | 정의 (상수는 코드에 고정: `K_POINTS=8, INTERIOR_PX=3, MAX_NEG=8, NEG_MIN_OVERLAP=0.01`) | 층 |
|---|---|---|
| `box` | E2-0 재계산(결정론 점검) | 대조 |
| **`pts`** | 양성 박스 + 마스크 **내부 양성 점 8개**: 원본 해상도 거리 변환으로 경계에서 ≥3 px인 화소 중 가장 깊은 점에서 시작하는 farthest-point 표집(후보 ≤20,000으로 결정론적 보폭 축소; 내부 화소 <8이면 마스크 전체) | **등록** |
| **`neg`** | 양성 박스 + **음성 박스** = 표적 박스와 교집합이 박스 면적의 ≥1%인 다른 c_ini 객체들의 꽉 맞는 박스(교집합 큰 순, ≤8) — 표적을 통째로 담는 배경 영역 포함 | **등록** |
| `ptsonly` | 내부 점 8개만(박스 없음) — 점 경로가 학습됐는지의 진단 | 탐색 |
| `negnc` | `neg`에서 표적 박스를 통째로 담는 음성은 제외(부분 겹침만) | 탐색 |
| `negall` | 양성 박스 + 다른 객체 **전부**를 음성으로(박스 중심 가까운 순, ≤8) — 쌍둥이 개체가 음성이 될 때의 효과 | 탐색 |
| `ptsneg` | 박스 + 내부 점 + `neg` 음성 | 탐색 |

측정은 E2-0과 동일(①·②·순위·후보 수) + 쌍별 채움 비율, 각 팔 − 박스의 쌍 대응 차, 프롬프트 구성(점 좌표·음성 id·박스) 기록.

## 3. 판정 규칙(고정) — 등록 팔 `pts`, `neg` 각각
- 살해 기준(E2-0과 동일): ① ≥ 0.8 이고 ② ≥ 0.7 이어야 "쓸 수 있는 예시".
- **박스 대비 채택**: ① 적중 ≥ 박스 ① 적중(15/20) **그리고** ② ≥ 0.7 **그리고** 쌍 대응 ② 적중 ≥ 박스(17/20) **그리고** 쌍 대응 후보 최고 IoU 차 중앙값 ≥ 0. 둘 다 채택 가능하면 ② 적중 → Δ 중앙값 순으로 고르고, 동률이면 `pts`(다른 객체의 마스크에 의존하지 않아 단순).
- 채택된 팔이 있으면 G-det의 예시 정의를 그 팔로 바꾸고, ① 기준은 그 팔의 값으로 다시 읽음(① ≥ 0.8 통과 시 E2-0의 재등록 결정 지점은 소멸). 없으면 박스 유지, 결정 지점 그대로.
- 탐색 팔은 보고만. 추가 보고: E2-0′ §6의 1위 오선택 7쌍과 등록 20쌍의 ② 실패 3쌍(FacePaint 2, Dog 3, Exhibit 5)의 회복 여부.

## 4. 예측
- `ptsonly` ①: 점 경로가 학습됐다면 ≥12/20, 아니면 <8/20 — **10~16/20**(자신 없음).
- `pts`: ① **15~17/20**, ② **17~19/20**(박스 이상). 쌍둥이·미소 객체는 불변; 이득이 있다면 채움 비율 낮은 쌍.
- `neg`: ① **16~18/20**(Dog 3·4, Exhibit 5는 이웃이 억제되어 오를 수 있음). 위험: 표적을 통째로 담는 배경 음성이 양성을 눌러 ①이 12/20 아래로 떨어질 수 있음 — 그러면 `negnc`가 분리해 보여줄 것. ② **16~19/20**, Dog 3·Exhibit 5 회복(+2 가능), 쌍둥이 불변(쌍둥이는 박스와 안 겹침).
- `negall`: 핀홀 쌍둥이(Blocks 5, Barn 2, MATF 2·3)에서 2~4쌍 손실, 초대형 영역은 `neg`와 같음.
- `ptsneg`: max(`pts`, `neg`) − 1 이상.
