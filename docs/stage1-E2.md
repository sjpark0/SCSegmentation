## 4. 해석
- **검출기는 개념을 찾지 개체를 고르지 않습니다.** 정상 쌍에서도 후보가 중앙값 5개이고 1위가 정답인 비율은 64%; 정답 없는 뷰에서도 98%가 후보를 내며 그중 73행은 1위 확률 0.8 이상입니다. 따라서 G-det 후보는 "그 개념처럼 보이는 모든 것"이고, 고르는 일은 전적으로 위치·기하·합의 신호의 몫입니다.
- 그런데 G-det의 고유 영역(반구 리그, 2,000 px 미만)은 **기하 신호(S2)가 없는 곳**입니다. 거기서는 후보 중 정답을 고를 수단이 합의(S1)뿐이고, 합의를 이룰 다른 생성기도 없습니다. 존재 55%가 있어도 선택 정확도 27%(F0 1위 정답 11/41)로는 G0을 대체할 수 없습니다 — P5의 교훈(잘못 놓인 시드가 이웃을 지움)과 같은 위험.
- 정답을 아예 못 찾는 F0 20쌍은 미소 객체(<500 px 다수)와 초대형 환경 영역(FlameSteak 37 149k px, CBABasketball 20 137k px)입니다. 1008 입력의 검출기 한계.
- 남기는 것: (i) 예시 주입 코드(스파이크·관문 스크립트)는 진단 도구로 유지. (ii) 정상 쌍 90%의 "후보 존재"는 **검증 신호**로 쓸 여지가 있음 — "G0 시드가 검출기 후보 중 하나와 IoU≥0.5인가"를 E5 신호 후보(S5)로 검토(등록 전 아이디어; 판정 아님).
