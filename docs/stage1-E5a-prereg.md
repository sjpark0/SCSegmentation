# S1-E5a 사전 등록 — 정답 없이 **나쁜 시드를 골라낼 수 있는가**: 기하 투영(S2)·후보 일치(S1)의 판별력

> 2026-09-10. [stage1-plan.md](stage1-plan.md) §5 S1-E5의 앞부분(S1·S2)만 떼어 등록합니다(S4 외형 포인터는 SAM 3 통과가 더 필요해 별도 등록).
> 사용자 결정(2026-09-10): 기하 두 팔(E4a·E4b)이 **생성기로는** 폐기됐으니, 만들어 둔 자세·깊이를 **검증 신호로만** 쓰는 길을 먼저 잰다.
> 층: **탐색**. 이 실험은 관문이 없고 판정도 하지 않습니다 — 신호의 판별력을 재서 다음 등록(무엇을 할지)의 근거만 만듭니다.

## 1. 왜 이게 가능할 수도 있는가 (측정된 사실)
- E4b: 정상 쌍의 투영은 **자리가 맞습니다** — 중심 오차 중앙값 0.126(정답 등가원 지름 단위), 깊이는 COLMAP MVS와 상대 오차 1.03%.
  투영이 좋은 **마스크**는 아니지만(J 중앙값 0.61), 검증은 좋은 마스크를 요구하지 않습니다.
- E4a: 환각 22%, E4b 29% — 검출 경로(98%)와 달리 "없는 곳에 없다"고 말합니다.
- F0의 41쌍 중 **38쌍이 "자리 틀림"**(빈 시드 3). 자리 틀림은 P5 면적 규칙이 **원리상 못 잡는** 부류입니다(P5 사전 등록 §1.1).

## 2. 신호 (전부 정답을 보지 않음; 대상은 원시 시드 `MVSeed_e0_index`)
| 이름 | 정의 | 플래그 규칙(등록 운영점) |
|---|---|---|
| `P5area` | **기준선**. (i) c_ini 프롬프트 면적 ≥ 64 px, (ii) 그 뷰에서 이 객체의 시드 면적 < `T(v) = max(64, 0.05 × v의 0 아닌 시드 면적 중앙값)`, 0 아닌 시드가 3개 미만이면 `T(v) = 64` (P5 사전 등록 §1.1의 조건 1~3; 조건 4 donor는 플래그 집합을 줄이기만 하므로 뺌) | 두 조건 모두 참 |
| `S2a_iou` / `S2b_iou` | IoU(원시 시드, E4a / E4b의 투영 `union`) | < 0.5 |
| `S2max_iou` | `max(S2a_iou, S2b_iou)` — 둘 중 하나라도 동의하면 통과 | < 0.5 |
| `S2a_ctr` / `S2b_ctr` | ‖중심(시드) − 중심(투영)‖ ÷ **투영**의 등가원 지름. 시드나 투영이 비면 `inf` | > 1.0 |
| `S1_rev` | IoU(원시 시드, 순서 뒤집기 시드 `MVSeed_e1_reverse`) — 후보 간 일치 | < 0.5 |

τ = 0.5는 계획 §4에서 이미 고정한 값이고, 중심 비 1.0(중심이 투영 지름 하나만큼 떨어짐)은 여기서 처음 고정합니다.
투영이 없는 장면·쌍(E4a의 미등록 4장면 등)은 투영을 **빈 마스크**로 취급합니다 — 즉 `S2a_iou = 0`, `S2a_ctr = inf`로 자동 플래그됩니다. 이것이 그 팔의 실제 운영 조건입니다.

## 4. 읽는 방법 (전부 보고; 판정·중단 규칙 없음)
1. **등록 운영점**에서 신호마다 적중(/38)과 오탐(/623).
2. **오탐을 맞춘 비교**: 연속 신호마다, N0 오탐 수가 `P5area`와 같아지는 임계에서의 적중 수. 점수 축이 다른 감지기를 공정히 비교하는 유일한 방법.
3. 크기 구간(<2k / 2k~10k / ≥10k)·리그(핀홀/반구)·시점 거리별 적중·오탐.
4. 조합 셋(고정): `S2max_iou<0.5 ∧ S1_rev<0.5`, `S2b_ctr>1.0 ∧ S1_rev<0.5`, `P5area ∨ S2max_iou<0.5`.
5. 정답 없는 132행에서 비어 있지 않은 시드가 몇 개이고 각 신호가 그중 몇 개를 잡는지.

## 5. 예측
- `P5area`: 적중 **14~18/38**, 오탐 **8~15/623** (계획에 적힌 16/38·11/619의 재현).
- `S2b_iou` (τ=0.5): 적중 **30~36/38**(자리 틀린 시드는 투영과 안 겹침) 그러나 오탐 **150~280/623** — 투영 자체가 정상 쌍의 38%에서 J≤0.5이므로. **운영점 그대로는 못 씀**.
- `S2b_ctr` (>1.0): 적중 **25~33/38**, 오탐 **60~150/623** — IoU보다 나을 것(자리는 맞고 모양만 나쁘므로).
- **오탐을 맞춘 비교(가장 중요)**: `P5area`와 같은 오탐 수에서 `S2b_ctr`의 적중 **10~22/38**. 16을 넘으면 기하 검증이 P5 규칙보다 낫다는 첫 증거이고, 밑돌면 이 길도 닫힙니다. 자신 없음.
- `S1_rev`: 적중 **8~15/38**, 오탐 **20~60/623**(E1에서 순서 변형이 F0 5쌍만 바꿨으므로 두 시드는 대체로 같음).
- 조합 `S2max_iou ∧ S1_rev`: 오탐이 크게 줄고(**10~40**) 적중도 줄어(**8~18**) `P5area`와 비슷한 자리에 놓일 것.
- 크기 의존: 적중은 큰 객체에서, 오탐은 작은 객체에서 몰릴 것(투영 품질의 크기 의존 때문).
