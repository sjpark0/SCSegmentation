## 1. 신호
`S4_cos` = **코사인**( c_ini에서 **정답 마스크**를 프롬프트로 넣었을 때 SAM 3 트래커가 만드는 객체 포인터,
그 뷰에서 **원시 시드 마스크**를 프롬프트로 넣었을 때의 객체 포인터 ).

- 포인터는 `sam3_tracker_base._use_mask_as_output`의 반환 6번째 값입니다. 그 함수는 (그 프레임의 backbone 특징, 마스크)만으로 포인터를 만들므로 **객체끼리 독립**입니다.
- 측정은 c_ini와 주석 카메라 2대만 담은 3프레임 유사동영상 한 세션에서, **(프레임, 객체)마다 새 obj_id**로 마스크를 넣어 서로 간섭하지 않게 합니다. 패키지 수정 없음(인스턴스 훅).
- 시드가 빈 (뷰, 객체)에는 포인터가 정의되지 않습니다 → **자동 플래그**(E5a에서 투영이 없을 때와 같은 규칙).
