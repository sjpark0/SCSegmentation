## 4. 읽기 (등록 규칙 §5)

1. **초기화 오차와 추적 오차가 갈라졌습니다.** 주석 카메라 3대의 시드를 정답으로 바꾸면 대조군 89.549 → **93.933**, 헤드라인 91.015 → **95.273**. 즉 남은 8.985점 중 **약 4.3~4.4점이 1단계(시드)**, 나머지 **4.7점(헤드라인)은 이 개입 뒤에도 남는 몫**입니다 — 단, 헤드라인에서는 채점하지 않는 이웃 카메라의 1단계 시드가 교차 시점 메모리에 그대로 들어가므로 "완벽한 시드에서 2단계가 잃는 것"이라고 단정할 수 없고(리뷰 2차 지적 3), 그 해석은 카메라를 독립 추적하는 **대조군(93.933, 잔여 6.067)** 에서만 성립합니다. 이득의 절반 이상은 실패 41쌍이 아니라 **정상 623쌍의 작은 시드 오차**에서 옵니다(N0 ΔJ&F +0.038, 148쌍이 0.05 이상 상승) — Table VI의 "+1.11(실패 15쌍)"이 시드 문제를 크게 과소평가하고 있었습니다.
2. **E6 환산식은 오라클 쪽에서 2.7배 낙관**(+2.967 → 실측 +1.093)이고 투표 쪽은 맞았습니다(−0.061 → −0.050). 원인은 쌍 수준에 보입니다: 프레임 0 IoU가 최대인 후보를 골라도 전파 뒤에는 F0 9쌍 회복·**4쌍 파괴**, N0는 +0.005뿐 — 프레임 0에서 최선인 시드가 전파에서도 최선은 아닙니다. 등록 규칙 4에 따라 "낙관 상한" 문구는 유지하되 크기(2.7배)를 원고에 적습니다.
3. **투표(R3)는 실측에서도 손실**(−0.050, CI가 0을 포함, 5↑/5↓; Blocks −2.17 · Fencing +2.75). E6 관문 실패 확정에 변화 없음(사후 채택 금지).
4. **R2의 단서**: 헤드라인의 closure 안 비주석 카메라는 G0 시드 그대로이므로 R2는 "주석 카메라 시드만 완벽"한 조건입니다.
5. P2 크기 오류의 뜻: 크롭 재추적(+0.951)과 정답 시드(+4.26)는 거의 **가산적**입니다 — 크롭이 회수하는 것(작은 객체의 해상도)과 시드가 회수하는 것(자리·모양)이 다른 오차라는 뜻이고, 이는 §VI-C의 "격자와 시드는 다른 양"이라는 서술과 맞습니다.
