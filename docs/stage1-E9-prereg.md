# S1-E9 사전 등록 — 1단계 경계 정밀도: 마스크 디코더 미세조정 (두 팔)

> 2026-10-14. 층: **확정(측정·채택 판정)**. 계기: [stage1-seedfail.md](stage1-seedfail.md) — 시드 비용 3.11점 중 좋은 시드(J&F ≥ 0.8, 605쌍)의
> **경계 ±2 px 띠 오차가 1.76점**이고, 정답 없이 쓰는 값싼 보정(SAM 3 다시 그리기, 띠 융합, 팽창·수축)은 전부 손해였습니다. 288 격자가
> 설명하는 몫은 그 빈틈의 약 1/4이므로 나머지는 **모델이 그린 경계 자체의 오차**입니다. 사용자 지시: "2번의 모델 수준 개선을 먼저해줘".
> 이 문서는 코드 구현과 GPU 학습 **전에** 커밋됩니다. §8 이후는 실행 뒤에 채웁니다.

## 1. 가설과 손잡이

채택 1단계 `geoset_pred_ft`(S1-E8 A, [stage1-E8.md](stage1-E8.md))의 학습 대상은 **기억 어텐션(`tracker.transformer.encoder`) + GeoBias**뿐이고,
마스크를 실제로 그리는 **SAM 3 마스크 디코더(`tracker.sam_mask_decoder`: 2층 양방향 트랜스포머, 업스케일 전치합성곱, 하이퍼네트워크 MLP,
IoU·존재 헤드)는 동결**입니다. 디코더는 비디오 추적용 가중치 그대로이며, 교차 시점 기억으로 조건화된 특징에서 경계를 그리는 데 맞춰진 적이 없습니다.

가설 H: **디코더를 같은 레시피로 미세조정하면 좋은 시드의 경계 오차가 줄고, 그 이득은 2단계(정지 물체 1:1 전달)로 거의 그대로 이어진다.**

범위 밖(이 등록에서 다루지 않음): c_ini 밖으로 넓어지는 범위(덜 덮음 22쌍 0.66), 닮은 객체 혼동(17쌍 0.45), 크롭 확대 디코딩(격자 몫, 상한 약 0.4).
이들은 E10 후보로 남깁니다.

## 2. 팔 (세 구성; 학습 두 팔은 `geoset_pred_ft`의 레시피·폴드·일정·seed 그대로)

| 팔 | arm | 학습 대상 | 손실 | 설명 |
|---|---|---|---|---|
| **D0** | `geoset_pred_ft` | (학습 없음, 채택 체크포인트) | — | 대조군 = 현재 헤드라인 1단계 |
| **D1** | `geoset_dec_ft` | 기억 어텐션 + GeoBias + **마스크 디코더** | 기존 그대로 (focal 20 · dice 1 · IoU L1 1 · presence 1) | 디코더만 추가 |
| **D2** | `geoset_decb_ft` | D1과 같음 | 기존 + **경계 띠 BCE** (W_BAND 1.0) | 경계를 겨냥한 손실 추가 |

고정 사항:
- 디코더의 학습률 **1e-5**(기억 어텐션과 같음), AdamW wd 0.01, 코사인, 3 epoch, frame stride 2, 두 번째 기억 확률 0.5·예측 기억·객체 게이트 τ 0.7, seed 0, 모델 선택 없음 — `geoset_pred_ft`와 동일.
- 디코더 중 `conv_s0`·`conv_s1`(고해상도 특징 1×1 합성곱)은 **제외**합니다: 학습 입력인 백본 특징 캐시(`Cache/sam3_feats`)에 이미 적용되어 구워져 있으므로 학습해도 캐시에는 반영되지 않고 추론에서만 바뀌어 학습·추론이 어긋납니다. `obj_ptr_proj`도 동결(기억 포인터 의미 보존).
- 경계 띠 BCE: 정답 마스크의 **원 해상도** 경계 띠 = dilate(GT, r) \ erode(GT, r), **r = 4 px**(9×9 max-pool; 288 격자 한 칸 6.7×3.75 px를 덮고 ±2 px 오라클 띠를 포함), 띠 화소의 BCE 평균(객체별 → 객체 평균; 표적 뷰에 없는 객체는 띠가 없으므로 0). 로짓은 기존 손실과 같은 `logits_to_original` 출력.
- 체크포인트에 `mask_decoder` 상태를 추가하고, 추론은 장면마다 체크포인트를 적재한 뒤 **디코더·기억 어텐션을 초기 가중치로 복원**합니다(폴드가 다른 다음 장면, 그리고 한 프로세스 파이프라인의 2단계가 원 가중치를 써야 하므로).
- 디코딩: 두 라운드, 게이트 `reproj`(채택 구성), k = 3, 1단계 CLI `scripts/run_geomem.sh all --arm <arm> --gate reproj --out <arm>_rep_e9 --r1-out <arm>_r1_e9`.
  한 프로세스 프리셋 `geoset_dec_rep`·`geoset_decb_rep`(`stage1/methods/geomem/stage1.py PRESETS`, `SCSam3/stage1_supply.py TAGS`).
- 학습 데이터 단서는 E8과 같습니다: MUVOD 다른 장면 정답으로 학습(장면 단위 5-fold, 같은 장면 누출 없음).

## 5. 채택 규칙 (실행 전 고정)

1. **1단계 관문**(팔별): G1 키프레임 J&F Δ > 0 이고 95 % CI 하한 > 0; G2 어떤 장면도 D0 − 0.01 아래로 떨어지지 않음(GeoSet-2 안전 규칙).
   통과한 팔만 2단계로 갑니다. 둘 다 미달이면 "효과 없음"으로 보고하고 끝냅니다(추가 변형·재학습·τ 조정 없음 — 더 돌리려면 새 등록).
2. **2단계 채택**(E8 §5와 같음, 기저 = 현 헤드라인 92.538): basic Δ > 0 이고 95 % CI 하한 > 0; 방어선 어느 장면도 basic Δ < −1.0 아님; complete Δ ≥ 0.
3. 통과한 팔이 둘이면 basic 점 추정이 높은 팔; 동률(< 0.05)이면 **D1**(단순한 쪽). 민감도로 98.33 % CI(본페로니 3)를 함께 보고.
4. 채택되면 헤드라인 1단계 프리셋을 그 팔로 바꾸고, 보고에는 E8의 학습 데이터 단서와 S2-R6 LOSO +0.387 병기를 그대로 둡니다.
