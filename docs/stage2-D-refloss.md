# 2단계 진단 — 기준 카메라 손실 1.52점은 드리프트가 아니라 **경계 정밀도**, 그중 **정지 물체를 다시 그리는 손실**은 회수 가능

> 2026-10-13. 등록 규칙 없는 기술 진단(GPU 0, CPU 약 30분). 사용자 요청("1번부터 진행해줘").
> 대상: E8 헤드라인 `SegMaskSam3XW1CGPS4MSdgeoset_repFsCs10kG2`(basic 92.173). 스크립트 `MVSeed/refloss/`(README 참조).
> 손실 = 벤치마크 가중치 × (1 − 쌍 평균 J&F), 합하면 100 − basic. 헤드라인 전체 손실 7.827, 그중 기준 카메라(c_ini) 1.521.

## 1. 방법별 기준 카메라 손실

| 출력 | 전체 손실 | 기준 카메라 손실 |
|---|---|---|
| E8 헤드라인 | 7.827 | **1.521** |
| E8 대조군 (XW0) | 9.289 | 1.939 |
| 정답 시드 헤드라인 (E7) | 4.727 | 1.531 |
| 정답 시드 대조군 (E7) | 6.067 | 1.939 |
| 제출본 헤드라인 | 8.985 | 1.588 |
| SAM 2 기준선 `SegMaskNew3` | 14.784 | 5.489 |

다른 카메라 시드를 정답으로 바꿔도 기준 카메라 손실은 그대로입니다(1.531). 헤드라인 구성(XW1 + CGPS4 + Cs10k + G2)은 대조군 대비 1.939 → 1.521로 줄였습니다(어느 요소의 몫인지는 이 비교로 가를 수 없습니다).

## 2. 손실의 모양

- **오차 종류**(프레임 단위): J&F ≥ 0.8인 작은 오차 81 %, 0.5~0.8 12 %, 놓침(예측 빈 마스크) 3 %, 정답 없는 프레임의 거짓 양성 2 %, J&F < 0.5 2 %.
- **시간**: 프레임당 손실이 프레임 1에 0.061, 5에 0.074, 20에 0.083. 프레임 1에서 이미 대부분이 생기고, 쌓이는 드리프트는 약 0.3점입니다.
- **집중도**: 398객체 중 상위 5개 12 %, 50개 49 %. 넓게 퍼져 있습니다.
- **격자 천장**: 정답을 288 격자로 왕복시키기만 해도 잃는 몫(`grid_ceiling.json`)이 기준 카메라 0.62점(41 %)입니다. 나머지 0.90점 중 크기별로는 ≥ 10,000 px 0.59, 2,000~10,000 px 0.26, < 2,000 px 0.05.

## 3. 오차는 정답 경계 바로 옆에 있습니다

| 오라클: 정답 경계에서 r px 안의 픽셀만 정답으로 고침 | 전체 손실 | 기준 카메라 |
|---|---|---|
| 없음 (현재) | 7.827 | 1.521 |
| r = 2 | 3.209 | 0.469 |
| r = 4 | 2.177 | 0.244 |
| r = 8 | 1.506 | 0.137 |
| r = 13 (bound_pix/2) | 1.349 | 0.121 |

- 기준 카메라 프레임 1–20 오차 픽셀의 95 %가 경계 13 px 안, 다른 카메라는 56 %.
- 빠뜨린 픽셀이 69 %(기준) / 75 %(다른 카메라). 큰 물체(≥ 10,000 px)는 예측이 1~3 % 작고, 작은 물체는 약간 큽니다. 17장면 모두 같은 방향.
- 경계 ±2 px 오라클이 손실을 절반 이상 지운다는 것은 오차가 "윤곽 전체가 1~2 px 어긋남 + 가는 구조"라는 뜻입니다. 정답 주석 자체의 정밀도도 이 규모라서 일부는 줄일 수 없는 바닥일 수 있습니다.

## 4. 값싼 후처리는 해롭습니다

| 후처리 | 전체 Δ | 기준 카메라 Δ |
|---|---|---|
| 팽창 1 / 2 / 3 / 5 px | −0.14 / −0.98 / −1.96 / −4.32 | −0.20 / −0.64 / −1.06 / −1.99 |
| 수축 2 px | −2.61 | −1.02 |
| guided filter (회색조, r 2~16, ε 1e-3~1e-2) | **−0.08 ~ −5.33** (16~17장면 하락) | −0.04 ~ −2.08 |

§3의 "큰 물체 1~3 % 작음"은 방향성 있는 치우침이지만 **균일한 팽창으로는 고쳐지지 않습니다**. 이미지 경계와 정답 경계도 픽셀 단위로 일치하지 않습니다.

## 5. 회수 가능한 몫 — 정지 물체

기준 카메라 프레임 1–20을 "정답 프레임 0 마스크를 그대로 복사했을 때의 J&F"로 나누면:

| 프레임 무리 | n | SAM 3 손실 | 프레임 0 복사 손실 |
|---|---|---|---|
| 정지 (복사 J&F ≥ 0.98) | 4,850 | **0.492** | **0.031** |
| 거의 정지 (0.9~0.98) | 1,044 | 0.200 | 0.237 |
| 움직임 (< 0.9) | 2,066 | 0.829 | 5.134 |

움직이지 않은 물체에서 SAM 3는 이미 정확히 아는 프롬프트를 매 프레임 다시 그리며 0.46점을 잃습니다.

정답 없이 쓸 수 있는 규칙 "IoU(예측_t, 프레임 0 출력) ≥ τ **그리고** 프레임 0 마스크 주변(31 px 팽창)의 평균 밝기 변화 ≤ δ이면 프레임 0 마스크 유지"의 격자(기준 카메라, 17장면 평균 basic Δ, `*` = 어느 장면의 장면별 Δ < −0.17; `MVSeed/refloss/sim2.py`):

| τ \ δ | 2 | 3 | 4 | 5 | 6 | 8 |
|---|---|---|---|---|---|---|
| 0.6 | +0.166 | +0.313 | +0.377 | +0.387 | +0.366* | +0.327* |
| 0.7 | +0.166 | +0.313 | +0.377 | +0.387 | +0.365* | +0.331* |
| 0.8 | +0.161 | +0.303 | **+0.365** | +0.370 | +0.346* | +0.314* |
| 0.9 | +0.134 | +0.243 | +0.291 | +0.299 | +0.282* | +0.269* |

- 프레임별 오라클(정지 판정을 정답으로) +0.516.
- leave-one-scene-out(16장면으로 고른 값을 남은 장면에): 이 표의 격자에서 **+0.387**(17/17번 (0.6, 5)), 좁은 격자(τ 0.8~0.97, δ 2~10)에서 +0.364. 문턱 선택만 덜어 낸 값이고, 규칙 계열을 이 정답으로 고른 몫은 남습니다.
- (0.8, 4)의 장면별 Δ: 최악 Fencing −0.059, Frog 0.000, 나머지 15장면 상승(최대 Dog +0.991).
- 다른 카메라에 1단계 시드로 같은 규칙을 걸면 손해(τ 0.85~0.95, δ 3~6에서 −0.02 ~ −0.22, 10~15장면 하락). 시드가 추적 결과보다 부정확하기 때문입니다.

## 6. 남는 것

- 기준 카메라에서 규칙으로 회수하지 못하는 몫: 격자 천장(0.62, 일부는 정지 규칙이 우회), 움직이는 물체의 경계(0.83), 드리프트(약 0.3).
- 다른 카메라 손실 6.31 중 놓침과 큰 오차가 0.90(14 %)으로, 시드·전파 실패는 다른 카메라 쪽에 있습니다.
- 경계 정밀도 자체를 올리는 것(고해상도 마스크 복원)이 가장 큰 남은 손잡이지만, 크롭 경로(S2-R1~R4)에서 이미 효율이 낮게 측정됐습니다.
