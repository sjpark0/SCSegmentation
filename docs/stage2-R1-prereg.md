# S2-R1 사전 등록 — 작은 객체의 크롭 추적 (유효 해상도)

> 2026-09-10. 사용자 결정: "B(2단계 해상도)를 빨리 먼저 확인하고 1단계로 돌아간다." 층: 탐색.
> 근거: [stage1-E0.md](stage1-E0.md) §3·§8 — 288 격자 손실은 매 프레임에 걸리고, 정답 시드를 준 기준 카메라에서도
> 2,000 px 미만 객체는 프레임 0 J 0.822 → 프레임 1~20 0.632. 봉투 +0.41(<2k)~+0.66점(<10k).

## 1. 가설
작은 객체를 **그 주변 크롭**(정사각, 시드 박스의 4배, 최소 256 px)으로 잘라 1008 입력에 크게 넣고 SAM 3 시간 추적을 돌린 뒤
전체 캔버스에 되붙이면, 유효 해상도가 4~10배가 되어 매 프레임 격자 손실이 줄고 프레임 1~20 J가 오른다.

## 2. 절차
- 대상: 17장면, 주석 카메라 3대(c_ini 포함), MUVOD basic 객체 중 **프레임 0 시드 면적 < 2,000 px**(Cr2k) / **< 10,000 px**(Cr10k, 탐색) — 정답이 아니라 **시드**로 고르므로 추론 시 쓸 수 있는 규칙.
- 프롬프트: c_ini는 정답 마스크(본류와 동일), 다른 카메라는 `MVSeed_e0_index` 시드(G0과 동일).
- 크롭: 시드 박스 중심, 변 s = clamp(4 × max(박스 폭, 높이), 256, min(H, W)), 이미지 안으로 밀어 넣음. 21프레임 고정(움직여서 창을 벗어나는 경우는 세어 보고).
- 추적: 객체당 단일 세션, 크롭 21프레임, 프레임 0 마스크 프롬프트, 앞으로 전파(이웃 읽기 없음 = XW0 조건). 크롭 밖은 0.
- 비교: 기준 폴더 `SegMaskSam3XW0MFs`(프레임 0 = 시드) 복사본에서 대상 객체의 프레임 1~20만 크롭 추적 결과로 교체 → `SegMaskSam3XW0MFsCr2k` / `…Cr10k`. `eval/eval_jf.py` → `report_jf.py --muvod`, 쌍별·장면별 Δ, 클러스터 CI.
- 실행: 장면당 전경 컨테이너 1회(객체별 세션, 모델 1회 로드). GPU 약 20~40분.

## 4. 읽기 규칙
- **S2-R1을 정식 팔로 등록하는 조건**: Cr2k 17장면 Δ ≥ **+0.2점** 그리고 어느 장면도 < −0.3점. 통과하면 크롭 규칙(창 크기·움직임 대응·대상 선별)을 다음 등록(S2-R1′)에서 다듬고 E7 구성 후보에 올림. 미달이면 "해상도 봉투는 크롭으로 못 연다"로 닫고 1단계로 복귀.
- Cr10k는 탐색 표만(판정 없음).
- 쌍 수준 표: 크기 구간 × 기준/비기준 × (오름/내림/동점), 창 이탈·빈 마스크 수.
