- 작은 객체를 시드 박스의 4배 창(최소 256 px)으로 잘라 SAM 3 시간 추적을 돌리고 되붙이면, 기준 카메라(정답 시드) <2k px 36쌍의 프레임 1~20 J가 **0.637 → 0.842**(예측 "≥0.75" ✔), 비기준 <2k 52쌍은 0.527 → 0.626.

## 5. 판정과 다음

- 등록 관문(Δ ≥ +0.2 그리고 장면 < −0.3 없음)을 **Cr10k+v2가 통과** → S2-R1을 **E7 구성 후보**로 올립니다: `--frame0-seed` + 작은 객체 크롭 추적(시드 <10k px, 창 4×·최소 256) + 게이트 v2. 구현은 `runMVSeg.py --crop-small <max_area>`(대상 객체를 별도 세션으로 추적해 되붙임)로 하고, 모드 C(이웃 읽기)와의 상호작용은 미측정이므로 E7에서 XW0M과 XW1CGPS4M 둘 다 돌립니다.
- 이득의 절반은 **정답 시드로도 못 넘던 해상도 천장**을 연 것이고, 나머지 절반은 시드가 나쁜 쌍을 2단계가 되잡은 것입니다. 1단계 시드 팔(E2~E6)의 판정은 원시 시드 J로 그대로 진행하되, 최종 E7의 상한이 올라갔음을 계획에 반영합니다.
- 남은 열린 것: (a) 줌<1.2 구간의 이득(문맥 정규화?) — E7 뒤 별도; (b) 대상 선별 상한(10k 대 더 큰 객체) — 봉투상 10k 이상은 손실이 작아 제외; (c) 프레임 0 시드 직기록이 "기준 추적기가 프레임 0에서 떨어뜨린 객체"(8쌍)에는 PNG를 쓰지 않는 구현 한계 — `--frame0-seed`에서 시드가 있으면 쓰도록 E7 구현 시 보완.
