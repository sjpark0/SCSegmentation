> (헤드라인 위 basic 91.0 / complete 86.4)을 **실제 실행**으로 대체합니다. 층: 구현 확인(게이트·대상 규칙은 R1″에서 고정,
> 여기서 바꾸지 않음). 이 실행이 이 구성의 **논문 수치**가 됩니다.

## 1. 구현 (본류 `runMVSeg.py`)
- `--crop-small <max_px>`(0 = 끔), `--crop-gate {none,v1,v2}`(기본 v2), `--crop-scale 4`, `--crop-min-side 256`. 접미 `Cs<max/1000>k` + 게이트 `G2`(예: `SegMaskSam3XW1CGPS4MFsCs10kG2`; 조립 폴더 `…Cr10kG2`와 구분).
- 위치: 본류 추적·쓰기 루프가 끝난 뒤(이웃 채널·전체 프레임 세션은 그대로), **채점 카메라의 각 대상 객체**(프롬프트 면적 0 < px < max; c_ini는 정답, 그 외는 시드)에 대해 크롭 세션(창 = 시드 박스 4배·최소 256·정사각·이미지 안, 21프레임 고정)을 같은 시간 예측기로 돌리고, 게이트(v1: 프레임 1 마스크·시드 IoU < 0.05 되돌림; v2: + 줌 < 1.2, 창 가장자리 접촉 ≥ 10프레임)를 통과한 쌍의 **프레임 1~20 PNG만** 크롭 결과로 덮어씀. 프레임 0은 `--frame0-seed` 규칙.
- 상호작용 정의: 크롭 결과는 이웃 기억으로 흘러가지 않고, 크롭 세션은 이웃 기억을 읽지 않음(= R1의 조립과 같은 정의; 통합 변형은 별도 등록).
- MANIFEST provenance `crop_small`: 규칙·대상·되돌린 쌍·소요 시간. 플래그 없으면 코드 경로·출력 바이트 동일.

## 2. 실행
`XVIEW=1 XMODE=C XGATE=1 XPTR=1 XSHIFT=4 XREF=muvod F0SEED=1 CROP=10000 CROPGATE=v2 SCSam3/runMVOptThree.sh <17장면>` → `SegMaskSam3XW1CGPS4MFsCs10kG2`. 채점 `eval_jf` → `report_jf --muvod`. 대조군 `SegMaskSam3XW1CGPS4M`(현재 헤드라인 90.0).

## 4. 읽기 규칙
- **헤드라인 채택 조건**: 17장면 basic Δ ≥ +0.5점, 어느 장면도 < −0.3, 비대상 바이트 동일(예측 b)로 구현이 R1 정의와 일치함이 확인될 것. 통과하면 헤드라인 = `SegMaskSam3XW1CGPS4MFsCs10kG2`, 분해에 "해상도(크롭) +약 1.0" 항목 추가.
- b가 깨지면(비대상이 달라짐) 원인을 적고 채택 보류.
