# 1차 결과 — 기준 프레임 다중시점 객체분리, 5개 방법 + 변형 2개

> **정정(2026-10-13)**: 이 문서의 `sam3_prop`(기존 1단계)은 사전순 카메라 사슬로 돌린 것이라 실제 1단계 G0(J&F 0.897)보다 6장면에서 약하고, 시점차 축도 사전순 위치로 쟀다. 기준선 비교와 시점차 표는 [results-baseline-fix.md](results-baseline-fix.md)를 따른다(예: A-3 − G0 = J +0.029, J&F +0.018). 우리 방법 간 비교는 그대로다.

> 2026-10-06. 규약은 [spec](superpowers/specs/2026-10-06-mvseg2d-benchmark-design.md) 2절. 입력은 장면당 기준 프레임
> N장 + 기준 카메라(c_ini) 정답 라벨맵 1장, 포즈 없음. 채점은 기준 카메라를 뺀 주석 카메라 2대 × 17장면 = **664쌍**,
> 객체별 J(IoU)와 DAVIS 경계 F. 모든 방법은 Docker 이미지(`scsam3`, `scgeo:pi3`, `scgeo:dino`) 안에서,
> RTX 6000 Ada 48 GB 1대로 돌렸다. 숫자는 `scores/*.json`에서 `mvseg2d.report`가 집계한 것을 그대로 옮겼다.

## 0. 헤드라인 (장면 평균 J&F)

"환각"은 대상 뷰 정답이 비어 있는 (카메라, 객체) 쌍에서 빈 마스크가 아닌 예측을 낸 수(평균에는 들어가지 않음).
시간은 장면별 RUN.json의 합(모델 로딩 포함, 2단 방법은 2단만). `pi3_sam3`·`dino_sam3`는 (카메라, 객체)마다 SAM 3
세션을 새로 여는 구현이라 느리다.

**읽기.** SAM 3 뷰=비디오 전파가 0.890으로 다른 모든 가족을 0.2 이상 앞선다. 재투영에 SAM 3 정제를 얹으면
J&F가 0.622 → 0.688로 오르지만 전파 기준선에는 한참 못 미친다. 카메라 순서(index vs 기준 중심 확장)는
0.004 차이로, 이전 프로젝트의 "순서는 원인이 아니다"라는 결론과 같다.

### 실패 장면 (평균에서 제외)

| method | 장면 | 원인 |
|---|---|---|
| pi3_reproj_hr, pi3hr_sam3 | AlexaMeadeExhibit, AlexaMeadeFacePaint, Dog, Welder | Pi3X 1M px × 41~46뷰에 CUDA OOM(약 51 GiB 요구 > 47 GiB). 규칙대로 장면별 해상도 하향 없이 실패로 기록. `pi3hr_sam3`는 원천 실패를 그대로 전파 |

첫 전체 실행에서 `pi3_sam3`·`pi3hr_sam3`·`dino_sam3`가 2560 px 이상 폭의 6장면에서 Triton 연결성분 커널 오류로
실패했다. 원인은 단일 프레임 SAM 3 모델의 `fill_hole_area`를 빌더 기본값 16으로 둔 것(기준선 `sam3_prop`과 이전
단일 프레임 스크립트는 0). 0으로 고친 뒤 **세 방법 모두 17장면 전부를 다시 돌렸고**(리뷰에서 6장면만 재실행해 설정이
섞여 있던 것을 지적받음), 모든 RUN.json이 `fill_hole_area: 0`과 같은 코드 커밋(fd99680; 6장면은 이 문서를 편집하던 중이라 `-dirty` 표시)을 기록한다.
재실행 전후 세 방법의 모든 표 값은 동일했다(GPU 결정성 재확인). 이 설정은 결과에
작지 않게 작용했다: Blocks `pi3_sam3`는 16에서 0.616, 0에서 0.698이다.

재투영에 SAM 3 정제를 얹은 이득은 중간 크기에서 가장 크고(+0.086), 작은 객체(+0.052)와 큰 객체(+0.057)에서는

없고, 포즈가 생기면 각도 거리로 다시 나눠야 한다.

## 5. 재현성과 실행 통계

- `sam3_prop` Blocks 2회 실행: 29쌍 J가 모두 동일(max |ΔJ| = 0.0).
- `pi3_reproj`는 6,210개 마스크를 썼다. `pi3_sam3`는 그 6,210개를 프롬프트로 썼고 그중 6,209개가 비어 있지 않은
  마스크로 돌아왔으며, 1,635개 (카메라, 객체)는 원천이 비어 빈 예측으로 남았다. `dino_sam3`는 964개 (카메라, 객체)에서 cos ≥ 0.5 후보가 없어 빈 예측이다.
- 환각(정답 없는 뷰에 마스크를 냄): 전파 14, 재투영 35, DINO 103. 대응 기반은 "없음"을 모른다.

## 6. 다음 단계에 남기는 질문

2차 후보인 사전학습 다중뷰 분할 모델(MV-SAM, 3AM, SegMASt3R, SegVGGT)과 포즈 기반 3D 리프팅(COLMAP+3DGS+
FlashSplat)은 아직 돌리지 않았다. 사전학습 모델은 코드·가중치 공개 여부부터 확인해야 하고, 포즈 기반 방법은
COLMAP이 PoznanStreet·Painter·Frog에서 실패한 전력과 어안 4장면 제외를 감안해 어느 장면에서 비교할지 정해야 한다.
