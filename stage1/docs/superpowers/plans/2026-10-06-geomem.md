# GeoMem-star Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A wrapper around the SAM 3 tracker that decodes every camera of a reference frame from the reference camera's memory alone (star topology) with a learned 3D positional embedding on memory keys and queries, trained by 5-fold scene cross-validation on MVSeg, and scored by the existing benchmark against `sam3_prop` (0.890) and the untrained `star` control.

**Architecture:** `geomem/` holds pure-numpy geometry (pointmap → 72×72 3D grid), the torch embedding module, a wrapper that calls the tracker's own `track_step` (reference memory) and `transformer.encoder` + `_forward_sam_heads` (target decoding), a cache builder, a training loop and a benchmark method. The upstream SAM 3 package is used in place and never modified. Host venv runs numpy tests; torch tests and all GPU work run in the `scsam3` image through `scripts/docker_run.sh`.

**Tech Stack:** Python 3.12; host venv (numpy, cv2, pytest); `scsam3` image (torch 2.10 CUDA, SAM 3 package at `../SCSegmentation/SCSam3/demoSCSam3MVOpt` and `../SCSegmentation/SCSam3/sam3`); `scgeo:pi3` for Pi3X. RTX 6000 Ada 48 GB.

**Spec:** `docs/superpowers/specs/2026-10-06-geomem-design.md`

## Global Constraints

- Upstream SAM 3 files are never edited. The wrapper calls `tracker.track_step`, `tracker.transformer.encoder`, `tracker._forward_sam_heads`, `tracker._get_tpos_enc`, `tracker.maskmem_tpos_enc`, `tracker.obj_ptr_proj` as they are (spec 3, 7).
- Tracker stays in `eval()` mode; training uses autograd only (spec 2, last row).
- Frozen always: image encoder, memory encoder (`maskmem_backbone`), SAM heads, pointer path. Trainable: `GeoEmbed` (all arms) and `tracker.transformer.encoder` (arm `geomem_ft` only) (spec 3.4).
- Geometry: pointmap in the reference camera frame, scale = median distance of valid points (conf > 0.1) to the reference origin; pooled to 72×72 by area average over valid points; cell valid iff valid ratio ≥ 0.25 (spec 3.2). Fourier features with 8 frequencies `2^k π`, k = 0..7 → 51 dims; MLP 51→128→128 GELU; key head 128→64, query head 128→256, both zero-initialised; `e_none` ∈ R^128 learned (spec 3.2).
- Star memory: one reference view; temporal row `maskmem_tpos_enc[num_maskmem - 1]` (= index 6); pointer temporal distance 1 with `max_abs_pos = 16` (spec 3.1).
- Training: samples (scene, t, r, v) with r ≠ v in the 3 annotated cameras; ≤ 16 objects per step (random subset); 5 scene-stratified folds from `geomem/folds.json`; AdamW, bf16 autocast, batch 1, cosine, 10 epochs fixed, no model selection; lr 1e-3 (GeoEmbed), 1e-5 (memory attention); weight decay 0.01; seed 0 (spec 4).
- Losses: sigmoid focal (weight 20, α 0.25, γ 2) + dice (1) on target-view mask logits at original resolution, L1 (1) on predicted IoU vs actual, BCE (1) on presence; `geomem_ssl` adds 0.5 × soft-dice reprojection consistency on 2–4 random unannotated views (spec 4.3–4.4).
- Benchmark output format and scorer are those of the first-round benchmark (`methods/common.py`, `mvseg2d/`). Eval scenes never appear in their own fold's training set (spec 4.2, 5).
- `fill_hole_area = 0` on the tracker (as `methods/sam3_single.py`).
- Ruling carried from planning: the loss formulas are implemented in `geomem/losses.py` (CPU-testable) rather than imported from `sam3/train/loss/loss_fns.py` (triton focal, no CPU path); same formulas.
- Commit after every task with the repo's attribution trailer.

## Review Focus

1. A view whose pointmap is invalid almost everywhere (hemisphere scenes, far cameras): pooled grid may be all-invalid; the embedding must fall back to `e_none` with no NaN. Tests in Task 2 (`test_pool_all_invalid_grid`) and Task 3 (`test_embed_all_none_cells_is_finite`).
2. An object present in the reference view but absent in the target (empty GT): presence target 0, mask target empty, loss finite and gradient defined. Test in Task 7 (`test_supervised_loss_absent_object_finite`).
3. A scene with more than 16 objects (CoffeeMartini 50): training subsamples, inference must decode all objects in one batch without silently dropping any. Test in Task 6 (`test_sample_object_cap`) and the Task 9 smoke assertion on object count.
4. Fold leakage: every scene in exactly one fold, hemisphere scenes in four distinct folds, and the benchmark method refuses a checkpoint whose fold contains the scene. Tests in Task 1 (`test_folds_partition`) and Task 9 (`test_run_refuses_leaking_checkpoint`).
5. A missing checkpoint for a scene's fold must produce a RUN.json error, never a silent fall-back to untrained weights. Test in Task 9 (`test_run_missing_checkpoint_is_error`).

**Files:**

**Interfaces:**

- Produces:
  - `local_points(depth, K) -> np.ndarray[h,w,3]` (pixel-index convention: `x = (u - K02)/K00 · z`, `y = (v - K12)/K11 · z`, `z = depth`; rows with depth 0 are zeros)
