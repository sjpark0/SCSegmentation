# GeoMem-2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a learned 3D-distance attention bias to the SAM 3 memory cross-attention (A-2) and a progressive multi-view memory set (A-3) on top of GeoMem-star, train four arms by the same 5-fold protocol, and score them against `geomem_ft`, `star`, `sam3_prop`.

**Architecture:** `geomem/bias.py` turns two views' 72×72 3D grids into an additive attention mask; `geomem/attn_patch.py` re-implements the cross-attention `RoPEAttention.forward` on the live instance so the mask reaches `F.scaled_dot_product_attention` (upstream files untouched); `geomem/wrapper.py` generalises the single reference memory to a `MemorySet` and can encode memories from predictions; `train.py`/`run.py` gain the arms, the third-camera memory sampling and the two-round inference.

**Tech Stack:** as GeoMem (host venv for numpy tests; `scsam3` container for torch/GPU; `scripts/test_torch.sh`).

**Spec:** `docs/superpowers/specs/2026-10-07-geomem2-design.md`

## Global Constraints

- Upstream SAM 3 files are never edited; the attention patch replaces the forward of the live `tracker.transformer.encoder.layers[*].cross_attn_image` instances only (spec 5).
- Bias: 16 RBF centres uniform on [0, 2], σ = 0.125, weights `w ∈ R^16` zero-initialised, `b_none` scalar zero-initialised for pairs with an invalid cell, pointer-token columns 0; mask shape `[1, 1, Lq, Lk]` with `Lq = 5184`, `Lk = M·5184 + 4M` (pointer tokens of all M memory views gathered at the END), broadcast over the object batch (spec 2.1, 2.2).
- Untrained model (zero heads, zero bias) must reproduce the untrained GeoMem (= `star`) outputs exactly (spec 2.1).
- `--no-rope` disables rotary encoding on BOTH q and k of the cross-attention (consistent), via the patch (spec 2.1).
- Memory set at inference: `{c_ini} ∪` up to the 3 nearest views by Pi3 camera-centre distance whose round-1 prediction is confident: mean predicted IoU over objects with presence logit > 0 is ≥ 0.7; a view with no confident neighbour uses `{c_ini}` only (spec 2.2). Fixed constants.
- Training: same as GeoMem (5 folds `geomem/folds.json`, stride 2, ≤16 objects, losses, AdamW 1e-3 embed/bias and 1e-5 attention, wd 0.01, cosine, 3 epochs, seed 0, no model selection); `geoset_ft` adds the third annotated camera's GT memory with probability 0.5 (spec 3).
- Arms: `geobias_ft`, `geobias_norope_ft`, `geobias_only_ft` (no 3D embedding), `geoset_ft` (+ round-1 output saved as `geoset_ft_r1`) (spec 2.3).
- `torch.set_autocast_cache_enabled(False)` stays on (via `sam3_single.load_model`); GPU jobs strictly sequential.
- Commit after every task with the repo's attribution trailer.

## Review Focus

1. Grids that are entirely invalid (far hemisphere cameras): every pair gets `b_none`, no NaN, attention still runs. Test in Task 1 (`test_bias_all_invalid_uses_b_none`).
2. The mask dtype under bf16 autocast: SDPA requires a float mask matching q's dtype (or bool); the patch must cast. Test in Task 2 (`test_patched_attention_runs_under_autocast_with_bias`).
3. A view with no confident neighbour in round 2 must give exactly the round-1 result. Test in Task 5 (`test_round2_without_neighbours_equals_round1`, GPU on Blocks with a forced-high threshold).
4. The memory set's pointer tokens: with M views all 4M pointer tokens must be excluded from RoPE; a wrong `num_obj_ptr_tokens` silently rotates pointer keys. Test in Task 3 (`test_memoryset_single_view_equals_refmemory_path` and `test_memoryset_two_views_shapes`).
5. The bias must apply to every memory view block with THAT view's grid, not the reference's. Test in Task 1 (`test_bias_blocks_use_each_views_grid`).

### Task 2: `geomem/attn_patch.py` — bias into the cross-attention

**Files:** Create `geomem/attn_patch.py`; Test `tests_torch/test_attn_patch.py` (GPU).

**Interfaces:**
- `patch_cross_attention(tracker, no_rope: bool = False) -> None`: for every layer `tracker.transformer.encoder.layers[i].cross_attn_image` (a `RoPEAttention`), binds a new `forward(q, k, v, num_k_exclude_rope=0)` that reproduces the upstream body (q/k/v projections, head split, RoPE on q and on the first `k.size(-2) - num_k_exclude_rope` keys with `rope_k_repeat`, SDPA, recombine, out_proj) with two changes: (a) `attn_mask = tracker._geo_attn_mask` (a `[1,1,Lq,Lk]` tensor or `None`) is passed to `F.scaled_dot_product_attention`, cast to `q.dtype`; (b) if `no_rope`, rotary encoding is skipped for both q and k. Idempotent (a second call does nothing). Sets `tracker._geo_attn_mask = None`, `tracker._geo_patched = True`.
- `set_attn_mask(tracker, mask: Tensor | None)` and context manager `attn_mask(tracker, mask)`.
- `unpatch_cross_attention(tracker)` restores the original bound forwards (kept on the instance as `_orig_forward`).

- [ ] **Step 1: Write failing tests (Blocks, GPU).** `test_patch_with_none_mask_is_byte_identical`: outputs of `GeoMemStar(use_geometry=False)` decode on cam0 before and after `patch_cross_attention(tracker)` are `torch.equal`. `test_zero_mask_is_byte_identical`: same with a zero mask set. `test_patched_attention_runs_under_autocast_with_bias`: a random mask of the right shape under `torch.autocast(bf16)` runs and changes the output (`not torch.equal`). `test_no_rope_changes_output`: `patch_cross_attention(tracker, no_rope=True)` on a fresh model changes the output vs patched-with-rope. `test_unpatch_restores`.
- [ ] **Step 2: Run, verify fail.** - [ ] **Step 3: Implement** (read `/opt/sam3/sam3/sam/transformer.py` `RoPEAttention.forward` inside the container and mirror it; use `apply_rotary_enc` / `apply_rotary_enc_real` as upstream does). - [ ] **Step 4: Run, verify pass.**

### Task 3: `MemorySet` in `geomem/wrapper.py`

**Files:** Modify `geomem/wrapper.py`; Test `tests_torch/test_wrapper.py` (add).

**Interfaces:**
- `@dataclass MemoryView: feats [5184,B,64], pos [5184,B,64], ptr_tokens [4,B,64], ptr_pos [4,B,64], p [5184,3], valid [5184], name: str`
- `@dataclass MemorySet: views: list[MemoryView]`; `prompt() -> (prompt [ΣL+4M,B,64], prompt_pos, num_ptr_tokens=4M)` with all pointer tokens gathered at the end in view order; `grids() -> list[(p, valid)]`.
- `GeoMemStar.__init__(model, geo_embed, geo_bias=None, use_geometry=True, use_bias=False, no_rope=False)`: when `use_bias`, calls `patch_cross_attention(tracker, no_rope)`.
- `encode_reference(image, backbone_out, masks_bool, p_ref, valid_ref, name="ref") -> MemorySet` (one view; unchanged numerics).
- `encode_memory_from_prediction(backbone_out, B, logits_1008 [B,1,1008,1008], presence [B], p_v, valid_v, name) -> MemoryView`: `tracker._encode_new_memory(image=None, current_vision_feats, feat_sizes, pred_masks_high_res=logits_1008, object_score_logits=presence[:,None], is_mask_from_pts=False)`; pointer = `obj_ptr` is not available from the memory encoder → use the pointer returned by `decode_view` (add `obj_ptr` to its output dict) and pass it in: signature gains `obj_ptr [B,256]`.
- `decode_view(backbone_out, B, memory: MemorySet, p_v, valid_v) -> dict(logits_1008, ious, presence, low_res, obj_ptr)`: builds the prompt from the set, computes the bias mask with `geo_bias(p_v, valid_v, memory.grids())` when `use_bias` and sets it on the tracker for the encoder call (cleared after), `num_obj_ptr_tokens = 4M`.
- `freeze(arm)` gains arms `geobias_ft`, `geobias_norope_ft`, `geobias_only_ft`, `geoset_ft` (bias + attention trainable; embedding trainable except for `geobias_only_ft`, where `use_geometry=False`).
