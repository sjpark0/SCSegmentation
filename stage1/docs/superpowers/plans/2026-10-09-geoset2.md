# GeoSet-2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the two-round memory set robust to wrong round-1 predictions with an object-level gate and predicted-memory training, on the `geobias_only` base, with a matched control.

**Architecture:** `MemoryView` gains a per-object confidence vector; `MemorySet.gate_mask` turns it into a `[B,1,1,ΣL]` additive attention mask that `decode_view` adds to the GeoBias mask. `methods/geomem/run.py` gets `--gate {view,obj}` and writes round-1 confidences. `geomem/train.py` gets two arms: `geoset_only_ft` (GT third-camera memory) and `geoset_pred_ft` (the model's own no-grad prediction on a random other camera as memory, gated).

**Tech Stack:** PyTorch inside the `scsam3` Docker image (`scripts/docker_run.sh`, `scripts/test_torch.sh`), host venv `.venv` for torch-free tests and scoring (`pytest tests/`, `mvseg2d.evaluate`, `mvseg2d.report`, `mvseg2d.paired`).

**Spec:** `docs/superpowers/specs/2026-10-09-geoset2-design.md`

## Global Constraints

- Never modify upstream SAM 3 files; the autocast weight cache stays off (`methods/sam3_single.load_model`).
- Never run two GPU jobs at once; all training and scoring goes into ONE background chain.
- τ = 0.7 (`TAU_CONF`), k = 3 (`K_NEIGHBOURS`), `EXTRA_MEM_PROB = 0.5`, 3 epochs, frame stride 2, AdamW (GeoBias 1e-3, memory attention 1e-5, wd 0.01) — unchanged from `geoset_ft`.
- New arms use the `geobias_only` base: `use_bias=True, use_geometry=False, no_rope=False`.
- With every `conf` all-True (or `None`) the decode path must be byte-identical to the current one.
- Result names: `<arm>_r1`, `<arm>` (r2 view gate), `<arm>_obj` (r2 object gate). Round-1 confidences go to `Result/<out>/round1_conf.json` of the two-round folder (amends spec 3.2: not into `_r1`, so an `--r1-out none` run still records them).
- Commit after each task on branch `geoquery-ptr` → rename to `geoset2` in Task 1 (`git branch -m geoset2`).

## Review Focus

1. A gated object whose memory view is the ONLY other view: the mask must leave the reference columns open, never a fully `-inf` row (NaN). Pinned by `test_gate_mask_reference_columns_open` (Task 1).
2. A view whose `conf` is all-False in `obj` mode must be dropped before encoding, not passed as an all-masked block; `views_dropped` counts it. Pinned by `test_object_gate_drops_unconfident_view` (Task 3).
3. `geoset_pred_ft` when the predicted view has no confident object: the step runs with one memory and logs `n_mem=1`, `gated_frac` blank. Pinned by `test_pred_memory_step_all_gated` (Task 5).
4. `random_memory_camera` on a scene with only the three annotated cameras cached (no `--all-views` cache) must raise `FileNotFoundError` naming the file, not KeyError or a silent GT fallback. Pinned by `test_load_sample_pred_memory_missing_cache` (Task 4).
5. `--gate obj --r1-out none` must not delete an existing `<arm>_r1` folder from the view run. Pinned by `test_r1_out_none_keeps_existing_r1` (Task 3).
