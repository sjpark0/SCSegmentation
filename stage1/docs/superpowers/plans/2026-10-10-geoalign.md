# GeoAlign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prediction-free memory views: align a neighbour view's 72×72 features to the reference grid (two-sided validity, holes filled with the reference's own features), attach the c_ini GT masks, encode with the existing reference encoder, and use k=3 such views as memory (arm `geoalign_ft`; round 2 adds A-3's predicted memory with the reproj gate).

**Architecture:** `geomem/align.py` gains `two_sided` validity and `fill_aligned`; `GeoMemStar.encode_aligned` swaps the level-72 map of the reference backbone and calls `encode_reference`. Training draws a random camera (`memory_rng`) and uses its aligned memory view; inference builds the 3 nearest views' aligned memories once per scene and shares them across targets.

**Tech Stack:** PyTorch in the `scsam3` image (`scripts/test_torch.sh`), host venv for torch-free tests and scoring.

**Spec:** `docs/superpowers/specs/2026-10-10-geoalign-design.md`

## Global Constraints

- Never modify upstream SAM 3; autocast cache off; never two GPU jobs at once (one background chain).
- `geoalign_ft` recipe = `geoset_only_ft`: geobias_only base, SAM 3 init, 3 epochs, frame stride 2, `EXTRA_MEM_PROB 0.5`, AdamW (GeoBias 1e-3, memory attention 1e-5, wd 0.01), cosine, 5-fold, no model selection; trainable params = `geobias_only_ft` (5,922,321).
- Two-sided validity `TWO_SIDED_TOL = 0.05` on `|z/depth − 1|`; existing `align_views` callers (GeoFuse) unchanged (`two_sided=False` default).
- Aligned memory views use the reference image, high-res levels and grid; only `backbone_fpn[2]` is replaced. Self-view alignment must give a memory byte-identical to the reference's.
- Inference memory = c_ini + the 3 nearest cameras (π³ centre distance, reference excluded) as aligned views, shared by all targets; round 2 adds predicted memory with `--gate reproj`. Result names `geoalign_ft_r1`, `geoalign_ft_rep`.
- Branch `geoalign` off `geomem`; commit after each task.

## Review Focus

1. A neighbour whose alignment is entirely invalid on the reference grid (e.g. a fisheye camera looking away): `fill_aligned` returns the reference's own features, the memory view equals the reference memory, and nothing crashes. Pinned by `test_fill_aligned_all_invalid_is_reference` (Task 1).
2. Reference camera among the 3 nearest: it must be excluded from the aligned views (its view is the reference memory already). Pinned by `test_aligned_views_exclude_reference` (Task 4).
3. A scene with fewer than 4 cameras: k clamps to the available neighbours. Pinned by `test_aligned_neighbours_small_scene` (Task 4).
4. Training sample whose level-72 cache lacks the drawn camera: `FileNotFoundError` naming the file, not a KeyError. Pinned by `test_load_sample_aligned_mem_missing_cache` (Task 3).
5. `encode_aligned` must not mutate the caller's `backbone_ref` dict (the same dict is reused for the target decode). Pinned by `test_encode_aligned_does_not_mutate_backbone` (Task 2).
